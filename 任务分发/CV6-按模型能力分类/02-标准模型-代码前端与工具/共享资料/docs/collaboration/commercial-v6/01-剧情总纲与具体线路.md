# 01：具体剧情总纲（待正式创作与验收的策划稿）

## 1. 定位与故事主轴

工作标题《街角牌局》，可更名。现代架空小城“澄川”，玩家接手一间曾是牌友聚点、如今冷清的街角卡店。旧招牌还在，固定牌友已经散去；玩家既要让这家店活下去，也要回答它最终服务怎样的人。

主要矛盾不是击败一个纯坏人，而是三种合理诉求：收藏者关心品相、来历与被认真对待；竞技者需要公平规则、稳定对手和有意义的赛场；经营者要保证现金流、供货和服务。玩家的决策改变客群、角色关系和店铺风格，不能只有不同台词、最后同一结果。

美术继续使用已有角色素材与皮肤系统；**故事角色的人格、职业、姓名与关系原创，不套用外观来源作品的人设**。外形和剧情 actor 身份分别绑定，同一存档里的命名角色必须有唯一持久身份，不能反复生成随机顾客替身。

## 3. 六章主线与经营/对战绑定

章节按条件推进，表中的时间是节奏建议，不是必须第几天触发。经营困难、失败或错过某次会面都有可继续路径；主线不依赖随机抽中特定稀有卡。

| 章 | 关键情节 | 真实玩法条件与分支 | 结尾带来的变化 |
| --- | --- | --- | --- |
| 序章《灯亮之前》 | 玩家开门准备，林澄拿着旧活动名单出现；赠盒已有真实系统来源 | 查看实际开店赠品；选择先卖货还是先熟悉收藏。剧情不能再次发一盒 | 知道柜台/货架/拆包台不同，记住首次选择，不强制花钱 |
| 第一章《第一张收据》 | 第一笔生意后，许遥发现旧活动照片中的普通卡；周野想找练习对象 | 实际成交触发收据场景；先接待收藏者或牌友会改变下一次会面/需求；两条可汇合 | 开放熟客联系与一项入门训练，完成首日日报复盘 |
| 第二章《留下来的那张牌》 | 一张被买家丢弃又被捡起的卡，引出“谁在意它” | 读真实弃牌/拾取/流通事件；若本局尚无弃牌，用独立的普通单卡委托替代，不造假日志 | 玩家决定留作店内展示还是按真实价格交易；市场线/关系线获得不同后续 |
| 第三章《牌桌不是摆设》 | 林澄愿意再试一次交流会，周野把店长视为挑战对象 | 店长通过实际训练/考核，或先只承办。对局胜负/托管/失败证据真实；失败能复赛、基础营业不锁死 | 分别建立牌技资格和承办记录，开顾衡店的邀请 |
| 第四章《隔壁街的邀请》 | 韩序带来社区活动邀请，玩家第一次离店 | 根据已批准离店政策歇业或安排员工；经过店外出入口、步行到邻近地点。不能仅改 roomId 就算世界完成 | 街区联系人、地点记录和跨店小赛成为长期扩展入口 |
| 第五章《名次与店名》 | 一次公开小赛中，竞技目标和接待压力同时出现 | 店长可参赛也可专注运营；拿名次、服务、预算分开评价。对顾衡输/赢产生不同对话与再挑战，而非剧情强制获胜 | 玩家看见自己的经营路线及其代价，角色对店铺的评价能追到事件 |
| 终章《下一场在这里》 | 旧活动名单不再是怀念，而是下一次邀约 | 玩家结合真实经营/牌技/承办记录选择未来定位：社区据点或竞技招牌；历史不足时给补足目标 | 两种等价的积极收束，之后继续自由经营、联赛与店外内容，不删档重开 |

完整发行内容目标是六章都能从新档走通，重要分支有可观察后果；先做首章纵向样本再估算其余文本/素材工作量，不先承诺未经测量的游玩小时数。

## 4. 三条角色支线

### 许遥：普通卡的名字

从一本缺页的收藏册开始。第一步认识一张实际存在的基础卡，第二步完成一次有来源的单卡交易/拾牌记录，第三步决定展示、出售或以后再谈。展示不等于免费新增库存；需要真实持有、保护/占用规则。出售按市场机制，未成交不写“已经卖掉”。没有目标卡可登记关注或换可用目标，主线不阻塞。

结局 A：留下有来历的店内陈列，获得后续收藏者会面；结局 B：把卡交到需要的人手里，获得真实委托信用。不是“卖就是坏结局”，也不自动无限发钱。

### 周野：赢一次之后

使用预算可获得的基础阵容练习，再挑战店长。玩家赢时周野学会调整，玩家输时他开始面对“赢牌不等于能经营”；第三次约战可改变规则，而非只加对手数值。教学借牌仅限训练会话，不能进入市场或代替正式构筑。NPC 模拟结果不能作为店长通过考核的证明。

### 林澄：名单上多一个人

先帮一位普通顾客完成接待，再筹备小型交流会，最后决定继续担任志愿者还是与店长保持平等合作。不是雇员的角色不会免费承担全天收银；若成为员工，薪资/排班走既有经营合同。邀请人数不足可延期，不能复制同一角色填席。

## 5. 首章详细流程与示例台词

下面是可交给 CV6-20 扩写的实际线路。`lineId` 是稳定文本 ID，不由显示文本生成；修改措辞不换 ID。界面里的“去做某件事”是导航/打开业务界面，不代表剧情已经完成交易。

| 场景/节点 | 台词与玩家选择 | 事件/条件及结果 |
| --- | --- | --- |
| `c01_arrival` | 林澄：“灯真的亮了。我还以为这块招牌只剩下照路的用处。” | 新档首次准备阶段可用；只出现一次，可稍后再聊 |
| `c01_question` | 玩家选“先把货摆好”／“这家店以前是什么样？” | 记选择与下一节点；不发钱、不改持卡 |
| `c01_shelf` | 林澄：“那我先不挡柜台。卖出去的第一包，记得给自己留张收据。” | 引导至货架；等待实际 sealed sale，不要求某个主题 |
| `c01_memory` | 林澄：“比赛日坐不下人。后来大家各忙各的，椅子倒是一张没少。” | 展示背景线索，随后同样进入经营等待 |
| `c01_wait_sale` | 任务追踪：“做成第一笔密封商品生意。” | 观察真实销量事件。缺货/价格/预算/打烊都给现有解释；跨日仍能继续 |
| `c01_receipt` | 许遥：“这张收据别丢。以后你会记得，第一位顾客到底买了什么。” | 使用真实交易摘要作插值，缺数据回退“第一笔生意”，不编造卡包名 |
| `c01_two_visitors` | 周野：“你这里能打牌吗？”许遥：“我只想找一张旧卡，不会占桌子。” | 两个身份是持久角色会面，不强行给他们生成一套参赛卡 |
| `c01_priority` | 玩家选“先聊收藏”／“先看练习”／“今天先把店顾好” | 前两项调整后续会面优先级；第三项给无惩罚的延后入口 |
| `c01_collection` | 许遥：“我找的不是最贵的那张。有人记得它，就够了。” | 打开收藏/市场解释，不要求现场抽中目标；解锁其支线关注 |
| `c01_practice` | 周野：“别让我挑最贵的。我想知道，手里这些牌能打到哪一步。” | 进入训练预告；只有能力已验证/有可用阵容时才能启动真实训练 |
| `c01_return` | 林澄：“先后没那么要紧。你答应了什么，明天还记得，就已经比空桌子好。” | 持久记录已承诺/延后，不把承诺当已完成 |
| `c01_close` | 日终玩家复盘：今天赚了多少？留下了哪张牌？明天先见谁？ | 真实日报与角色线索并排；任务奖励不当主营利润，不强制留卡 |

CV6-20 要补每个场景的开始/结束/取消/重入台词、缺人/缺货/跨日/读档分支，以及首章两条角色支线的完整文本。仅交这张表的复述不算完成台本。

## 6. 文风与编辑原则

对话短、具体，让角色谈自己的目的和担忧；不让每个 NPC 都念教程。重复说明放游戏手册，角色只给当下提示。玩家选择必须说明可见代价；如果只是口味选项，不能伪装重大路线。

命名角色人格与外形皮肤分离，中文姓名与稳定内容 ID 固定。卡牌强度、稀有度、人物外形、财富和道德不建立偷懒的对应关系。重要事实来自实际事件或明确的作者背景，不用“本店故事日志”编造已发生经营结果。

对话可回看、文字速度可调、可跳过已允许的演出；跳过不会代替玩家确认买卖、参赛、旅行或关键选择。玩家可稍后再谈，不靠频繁弹窗逼其推进。主线/支线和自由经营互不抢唯一镜头或输入控制。

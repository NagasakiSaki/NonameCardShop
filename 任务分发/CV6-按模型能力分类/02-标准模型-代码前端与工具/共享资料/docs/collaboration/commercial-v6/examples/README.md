# 首章结构示例

`chapter01.sample.json` 是文档草案，schemaVersion=0，不是当前游戏已支持的API或可直接加载内容。没有改正式data目录。

例子给出稳定line/node/choice/effect ID、选择→等待实际成交→角色对话→记录下次会面偏好的完整关系。它不生成钱/卡，不把练习邀请当真实资格。图结构可检查，业务谓词/动作须由CV6-21冻结并由23校验/运行。

此例把文本内联仅便于单文件阅读。正式编辑项目按02规格拆出text/zh-CN.json与流程源，不能同时维护两份真源。人物需实际绑定/排期，本例不生成NPC分身。候选导入工具应拒绝未批准版本，而不是把本例默认为正式内容。

# 强推理审查模型（缺位时主模型负责小门槛）：本包先读

除16独立全项目审计外，本组重点是接口冻结、风险评审和独立验收，不要求代写整包。源码实现与自测优先交标准代码模型。没有外部强模型时，主模型只做这些小门槛；同包作者不得自称独立审计。

这是能力分类目录，不代表每个任务都尚未开始。先核对共享资料的 task-board.json 中 acceptedStage/remaining，再执行用户分配给你的剩余范围，不重做已接入阶段，不因为共享资料包含26包就同时开展。

## 可以直接复制给模型的话

请先读本文件，再读用户指定的任务书。共用规范见本组 `共享资料/docs/collaboration/commercial-v6/`。只做本文件指定的角色/阶段与可写目录，先记录实际基线；交完整候选、DELIVERY/manifest/gaps和必要证据。不要提交正式工程、清存档、覆盖原图、更新EXE或自行联系其他模型。高风险实现/审查分目录，不互改。

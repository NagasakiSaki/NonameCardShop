## 目标

把成熟经营游戏的可观察机制转成可实施的小决策循环，提供取舍而不是一串功能愿望。

## 最小只读输入

## 分步工作

1. A：优先复用共享参考。研究 TCG Card Shop Simulator、Moonlighter、Recettear 三个直接相关项目；再分析 OpenRCT2 或 OpenTTD 一个开源扩展/维护实例。每项至少一条官方出处，标访问日期、版本/分支。没有实际试玩不得写试玩结论。

2. B：逐项拆出玩家输入、消耗、等待、反馈、收益/损失、下一次选择；按本作现有功能说明差异。给 8～12 条具体可用方案，每条写成本、可组合性及不能照搬的原因。

3. C：排序成 3 个首批实验和延后表，画经营→构筑→考核→赛事→需求的链。首批每项只需一个完整样例，不要求同时复制所有原作系统。

## 验收标准

每条结论标证据种类、输入/基线与未覆盖项；仅跑本包必要场景。当前已实现 API 与共享草案新 API 分开；没有绑定的接口写候选，不填假数据 0 或假成功。

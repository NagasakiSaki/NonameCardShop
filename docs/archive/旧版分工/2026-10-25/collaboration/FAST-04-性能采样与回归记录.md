## 四个固定场景

1. 普通营业：当前默认配置与真实 Host，记录实际场景输入。
2. 繁忙营业：合法容量内人数，不能解除 NPC 上限当普通满载。达不到就写未达到，不伪造成功。
3. 较大库存：隔离合成 1000 张测试实物，明确不是经营所得；比较卡表/垃圾桶/经营页加载，数据不支持该前置就列限制。
4. 开关窗口 20 次：交易/经营/垃圾桶，测首屏、关闭恢复、订阅/timer/慢响应是否遗留。候选未接入时测当前正式版，候选接好后只补受影响场景。

每个代表场景 30～60 秒，冷/热启动分开，必要重复而非长时间空转。记录帧间隔 p50/p95、长任务次数/时长、操作到可见反馈、查询/首屏耗时及错误。测不到的 API 写 null/未测；内存 API 不支持不能填估值。

可对稳定停摆/资源错误交一次最小复现及截图/日志；不要循环跑全库测试、批量造理论 Bug。平均 fps 不等于交互顺畅，20 次循环没报错也不等于证明无内存泄漏。

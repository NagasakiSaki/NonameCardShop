# V7 分工：高手挑战、卡包成长、多模式与场景对话

日期：2026-10-25。源码基线 `8e3313e9`，内核本地版本 `1.11.6`。本轮只编写方案、接口草案、协作样例和分发包，**游戏尚未按本方案改动**。当前运行版仍为原价格、原卡包列表和 KOF/BO3。

本轮规则覆盖 V6 中重叠的定价、解锁、对话入口和赛制安排；V6 的长期维护、剧情编辑器、未来地图等不冲突任务继续保留。已经接入的剧情 VM、内容版本、存档回执和暂停租约继续复用，暂不创作新剧情台本。

## 分给谁

| 包 | 一组承担的一系列任务 | 模型能力 | 最终整合 |
| --- | --- | --- | --- |
| [A 经济与卡包](任务书/V7-A-经济与卡包.md) | 三档价格、分层预算、停产主题、单包开局、供货门槛、配盒与版本迁移策略、经济采样 | 标准代码模型；高速模型可帮数据核对 | 主模型接采购/交易与规则配置 |
| [B 高手与约战](任务书/V7-B-高手与约战.md) | 三日调度、主动/被动约战、延期重来、挑战借用阵容、解锁/招募、助力、存档状态机 | 能写状态机的标准模型；高风险由主模型审查 | 主模型接世界事务、来访和收益 |
| [C 赛制与系列赛](任务书/V7-C-赛制与系列赛.md) | 四赛制注册、备战/逐局选将、地主换边、阵营与席位方案、BO3归约、锁卡与中断策略 | 标准代码模型，需严谨测试 | 主模型接 matches/queue/结算 |
| [D 无名杀适配](任务书/V7-D-无名杀适配.md) | 本地斗地主/2v2原生模式调查、三/四座桥接、人机分工、可信赛果、能力探测与旧模式回归 | 唯一高质量模型优先给 D；不可用时由主模型承担 | 主模型审桥接与真实引擎证据 |
| [E 场景对话与前端](任务书/V7-E-场景对话与前端.md) | 场景触发对话、NPC点击/走近、紫名高手、约战菜单、四模式开桌、多轮选将、助力与解锁反馈 | 前端模型；必须能看截图 | 主模型接真实 Host 与世界事件 |
| [F 独立审计与验收](任务书/V7-F-独立审计与验收.md) | 跨模块不变量、经济与45天进度样例、引擎证据审查、旧档反例、浏览器验收脚本 | 独立代码/浏览器模型，不与同包作者共用自评 | 主模型运行最终整合测试 |

每组写完整候选和本组适配建议，**不修改正式源码或其他组交付**。A～F 都可以现在开工，不需要等待别人先完成。缺另组实现时使用随包共享合同与 fixture 完成本组模块、失败出口、自测和接入说明，不能只交接口空壳，也不能把 mock 验收冒充正式联调通过。

共享文件：

- [冻结玩法与默认参数](01-冻结玩法与默认参数.md)：用户要求、设计默认值与边界。
- [共享接口与数据归属](02-共享接口与数据归属.md)：合同、权威状态、命令事件与错误。

可直接转交的独立文件夹与 ZIP 位于工程 `任务分发/V7-高手挑战与多模式/`。每包内含本组任务书和共同规则。任务状态一律从 `任务登记.json` 查看，本轮不能标成已开发完成。

如果只有一个高质量模型：优先让它做 D；A/B/C 给标准模型分步写完整候选，E 给前端模型，F 保持独立。主模型负责共享政策、原子结算、迁移和合并，不要求任何组停下来等高质量模型回应。

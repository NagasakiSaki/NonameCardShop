# V7-E：场景对话、NPC约战与四模式开桌

交给高速前端模型，必须能运行浏览器并查看截图；不需要重绘素材或另找高质量模型设计后端。只写 `deliverables/operations-v7/V7-E/`。以共享Host草案和隔离fixture实现，不等后端，不能自行改后端或引擎桥；真实接线由主模型完成。

## 连续任务

1. 做世界内底部DialogueOverlay，场景保留在后方；已有细致头像/立绘、姓名、分页文本/选项。尺寸/输入见01，桌面和390px窄屏、短窗口、缩放均无正文/选项溢出。不能继续把章节列表做成主交互，旧故事入口保留为回看/兼容。
2. NPC点击/触控/键盘就近对话意图：点击远处先请求合法接近/寻路，到范围再actors.interact；目标离开/被占/读档要取消旧pending。不能瞬移NPC，不能从UI自行宣布来访成功。角色点选与设施/世界行走避免互相吞操作。
3. 紫名高手：复用bd-tomori等现有sprite和立绘，头顶适中中文名+身份文字/图标，颜色有对比度；一般客中文名保留。昵称相同/外形相同不能当同一actorId。
4. 主动邀请overlay队列：空闲/在场/够近/页面可见才呈现；玩家别的窗口/比赛中排队，不能弹窗覆盖。选接战→准备，改天/Esc→持久延期；同一offer重复click/关闭回调/迟到响应幂等。普通NPC点击提供约战/交谈/离开等必要业务菜单，不创作剧情。
5. 开桌模式选项四种，显示备战人数、AI队友和可用原因；保持开台费调整、等待时自由移动。合同fixture模拟不可用/卡不足/桌满/角色忙，真实后端状态将来由主模型接。
6. 选将分两层：整场5/8备战池选满一次确认；每局从固定池选1或2，标出主将human/同伴AI、地主/农民阵营及剩余位置。卡面/技能预览、收藏置顶、数量/占用、分页、跨页选择不丢；不要每选一个重新弹整个窗口。
7. BO3比分/换边/下一局和中断提示，玩家死而AI仍在显示观战而非输；准备/对话/对战租约交接，失败返回可恢复页面。不会调用假引擎，只消费host.battle挂载接口。
8. 供货页210/360/510及锁主题预览、挑战提示；通关解锁与伙伴加入反馈、岗位/停用/上限页。价格由DTO取，不写死在UI；借用阵容明确标识，不能当收藏卡上架。
9. 保存/读档旧窗口关停、返回世界、ResultUnknown用同requestId核对/重试；证明没有泄漏lease/重复约战、键盘穿透、世界点击穿透。
10. 交完整可操作fixture试验入口、浏览器脚本/截图、真实接线adapter与frontend热点建议补丁，不修改现有narrative内容或VM。

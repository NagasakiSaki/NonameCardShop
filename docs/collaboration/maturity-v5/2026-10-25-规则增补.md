# 规则增补：后续任务优先读取

用户暂时保留成熟版规划，先修改现有开发版。本增补不代表 MV5 任务已下发。

1. 新档散包建议零售价约 100/200/300 三档，对应进货 70/140/210；盒按 24 包与折扣计算。新资源收益模型与适用限制见 [实装记录](../../audits/2026-10-25-三档价格与对战规则.md)。

3. **KOF 取消手牌继承，换将时前将牌丢弃，继任者重新摸四张。** 审计与新赛制兼容验收必须验证 fresh-four；不可按旧 CORE4 的继承测试恢复旧规则。
4. MV5 文档中提到“当前所有比赛串行冻结”“手牌继承”的地方均是先前基线描述，以本增补为准。抽象新格式时保留最新规则，不保留被用户取消的行为。

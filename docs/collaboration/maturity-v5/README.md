## 方向

保留 Phaser、现有细致像素素材、真实武将卡面与无名杀规则。成熟版的核心循环是：

**观察需求 → 进货/流通 → 零售与收卡 → 构筑参赛 → 参加考核/举办赛事 → 获得经营资格、客群与声誉 → 选择下一轮投资。**

打牌成为独立的技术考核与经营内容；经营成绩、店长牌技、办赛服务分别评价。不能用抽到 SSR、挂机赚够钱或 NPC 模拟战绩替代店长牌技，也不能一次败北就让存档无法继续。

内核兼容的目标是：**未来经过已定义的检测与迁移后，可以独立换入受支持的无名杀版本，失败能回退。** 不承诺任何上游破坏性更新都无需适配、所有旧录像都能跨版本重播。

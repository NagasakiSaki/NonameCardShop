## 1. 产品目标

把游戏做成有明确故事、持续经营取舍、真实对战考核和可重复赛事的完整单机作品：玩家经营一家社区卡店，逐步建立自己的经营风格和牌友圈。剧情通过实际经营与打牌推进，角色也能在店外相遇。故事结束后仍可自由经营。

“商业水平”按完整度、可读性、稳定性、内容制作效率和发布维护验收，不以功能数量或一句“可商用”代替。付费发行前的代码/素材来源与授权核对列入发布任务；本方案不是确认既有第三方素材均可直接商业发行。

## 2. 本轮必须保留的现行规则

- 新档散包建议售价 100/200/300，进货 70/140/210，盒为 24 包；当前资源收益评分仍是理论估算，复杂武将待复核。
- NPC 对战不暂停经营、不在结束额外加半小时；只有玩家对战持有比赛暂停，并在整场结束结算一次 30 分钟。普通交互窗口自动暂停继续保留。
- KOF 换将弃前将手牌，新将重新摸四张，不再继承；BO3、队列、收藏/保护与实际持卡资格继续兼容。
- 即时采购；固定配盒/小保底；密封零售和单卡市场分开；顾客开包/拾牌登记流通；玩家使用自有卡不限流通，NPC 受持有/流通限制。
- 新档赠盒、自动任务与流水、日初存档语义保留；旧盒内容、成本、已接受费用和用户存档不可因改版静默重写。
- Phaser、现有像素素材、真实卡面、无名杀外部桥接继续使用；玩法、剧情和引擎三个版本分别维护。

## 5. 主模型做什么，外部模型做什么

外部模型交完整候选实现、目标路径补丁、自测与证据；17 做机械集成与冲突整理，16 做独立复现，原作者返工。主模型集中在产品/合同冻结、资金/剧情副作用与迁移的高风险判断、关键证据抽查、正式合并与私有发布。不要把新包再退化成“外部只写 demo，主模型重写所有后端”。

无需同时运行 26 个模型，也不依赖额外高质量模型。推荐四条高速线轮换，审计交叉进行。首批可发 **CV6-19（剧情总案）、CV6-21A（运行合同）、CV6-24A（地图注册盘点）、CV6-17A（交付沙盒）**；空闲模型可并行做 01 或 02。22/23 可先做接口与小样例，正式实现等首版内容合同冻结。

## 6. 实施顺序

先做一段完整的店内首章：编辑工具写内容 → 校验预览 → 正式游戏对话/经营/真实考核 → 存档与重试。再让一个小街区接入相同剧情接口和离店政策；最后扩充六章与重复经营、赛事和发布资料。不能把“世界接口已经有了”写成“大地图已经可玩”，也不能以数量替代首章打磨。

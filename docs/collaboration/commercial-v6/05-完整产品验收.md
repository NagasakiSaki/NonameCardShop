# 05：面向完整作品的验收与发布门槛

所有条目都是未来验收计划，不是已通过报告。“商业水平”需要可观察证据和稳定制作流程，不是一口气把所有未来玩法都塞进首版。

## 1. 首版质量范围

必需：完整可继续的经营循环、六章主线和主要角色线、真实牌技/承办目标、一个可回访店外街区、可重复赛事、可用剧情编辑器与内容构建、旧档兼容、设置与维护手册。多人联机、全城地图、第二门店、完整战斗随机状态恢复、配音和豪华装修编辑器可以后置。

游戏模式应明确“跟随剧情”和自由经营的关系。首次建议剧情引导，但可稍后推进；自由经营不强迫自动完成剧情，不用跳过剧情领取一整套未完成任务奖励。重要选择可知其影响方向，不能靠剧透隐藏唯一正确答案。

## 3. 完整性和可用性

- 每章有可开始、可结束、可重入、可延后和失败处理；结局不删档，后续经营仍有目标。
- 所有正式可点击入口有实际行为或清楚的未开放解释；没有“点了没反应”或依赖 debug 控制台推进的主线。
- 台词、任务、经营指标、配图和对战规则一致。剧情不再说签收新订单或 KOF 继承手牌。
- 玩家界面使用玩家语言，工具界面保留必要技术诊断。正文/选项可调文字速度，音量独立、静音仍能理解重要信息；不只靠颜色区分成功失败。
- 文本至少有稳定 lineId 与完整简体中文；翻译接口保留，首版不冒称已有多语言。跳过/回看不改变业务结果或泄露未来资格。

## 4. 工程与维护

配置、内容、编辑源、编译产物、素材与内核分层；稳定ID/注册表代替中央长 if 链。自动化检查覆盖内容schema、资源引用、构建、升级与定向测试，不强制每次跑所有浏览器/内核组合。性能阈值基于实际设备先测量，再设预算；报告 p95 等数据必须给采样环境/数量，不能用空白 demo FPS 代表正式游戏。

重大问题分级：P0 丢档/重发钱卡/伪造正式结果；P1 主线或经营停摆、资金/人物永久锁死、编辑保存丢内容；P2 局部功能/体验；P3 低影响显示。发行候选无已知阻塞 P0/P1；未覆盖场景和已知限制公开。

“像素图有开源工具”“代码项目是开源”不代表所用角色原图、音乐、字体和所有发行方式已获许可。18 只登记实际来源/条款/授权证据和缺口，必要时安排原创/许可替换；不在策划阶段冒作法律结论或阻塞其余原型工作。

## 5. 发布交付

源码/内容/profile/素材版本表、可重建命令、安装/启动/回退手册、玩家设置与存档说明、编辑器教程、内容作者规范、问题/限制清单齐全。EXE 独立验收，不把浏览器测试通过等同桌面发行通过；是否正式更新安装包由用户另定。

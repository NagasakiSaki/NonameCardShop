# 新邦五团人物外观与工具说明

2026-10-24。此项为已实现的外观扩展；完整交易页面重建仍按《下一版前端重建开发文档》等待实施。本轮未重建 exe，也未清空玩家存档。

## 已实现

用户确认的范围为 MyGO!!!!!、Ave Mujica、梦限大みゅーたいぷ、millsage、一家Dumb Rock!，每团 5 人，共 25 人。

- 25 套 96×96 独立头像，以及 64×64 四向八帧行走图集；配色、发型、挑染、发饰和服装主色可由代码修改。
- 已接入美术试验页的按团筛选、选人预览与 PNG/JSON 导出。
- 已接入正式游戏「设置 → 店长换装」和顾客外观池。顾客数量仍按原规则限制，不为展示 25 人增加营业客流。外观轮换顺序跨团分散，不消耗经营随机数。
- 默认店长采用之前认可的基础行走素材；六套旧皮肤 ID 保留兼容。动画、帧尺寸和落脚点改为按各自清单读取，换皮时同步更新。
- 顾客姓名池为 30 个国际化姓名，如 Maya Chen、Alex Rivera、Amara Okafor、Yuki Sato、Leila Haddad。三位常客保留原 actorId、预算、收藏、委托与关系，只更新姓名和外观。
- 加载旧档时只替换原内置姓名池和旧默认姓名；自定义姓名保留。导入与按天读档同样应用外观迁移，不修改卡牌归属、资金、订单或已生成盒内容。

原作角色名只用作美术选择器中的外观参考名。店内姓名、职业、拾荒资格、贫富与购买偏好独立，不套原角色人设。

## 工具与交接

其他模型直接阅读 [MODEL-GUIDE.md](../experiments/character-art/MODEL-GUIDE.md)。使用普通 JSON、JavaScript 和 Node CLI，不需要当前对话、API 密钥或安装绘图插件。基础部件、来源哈希、生成器与署名均在工程中。

预览入口：`http://127.0.0.1:5190/experiments/character-art/index.html`。导出图册：`experiments/character-art/generated/gallery.html`。汇总图每行一团，依次为 MyGO、Mujica、梦限大、millsage、一家Dumb Rock。

当前为首版像素化重组：轮廓、眼色、主色和识别性饰品已落地，舞台服的复杂剪裁、格纹、花边和发束可继续精修。未将基础组件的开源许可视为 BanG Dream 原角色设计的授权；官方参考图留在本地参考缓存，不随工程分发。

## 与后续前端开发的分工

美术模型可调整 `data/band-appearances.mjs`、人物试验工具与新增图层，输出独立文件；交易前端模型按重建文档工作。美术任务不改 Host、卡池、卡价、存档和对战引擎。最终由主工程集成人员安装完整人物包并合并资源清单。

不要重新使用旧生成器覆盖这一套人物。`tools/frontend-art/build.mjs` 已接入新人物包安装器；修改该构建器时必须保留接入。

## 本轮验证

- `npm run art:install`：28 套模板生成，透明底、表情、调色、四向差异与确定性输出通过。
- `node tests/frontend/assets.mjs`：12 项资源/清单/导航检查通过。
- `node tests/customer-identity.mjs`：姓名迁移重复执行无副作用，自定义姓名、资金与卡牌归属保持。
- `node tests/distribution-skins.mjs`：旧订单、配盒和存档换装兼容检查通过。
- `node tests/frontend-skins.mjs`：25 套新皮肤和旧 ID 切换、64/96 混合规格、落脚点、左右侧面、窗口暂停与刷新后恢复通过。
- 实际内置浏览器已查看按团筛选、人物头像与场景显示；使用独立试验页，未对玩家存档执行测试操作。

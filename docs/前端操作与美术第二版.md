# 前端操作与美术第二版

2026-10-23 · 源码开发版，未重新打包 EXE。

本轮针对四向输入受限、素材细节不足、设施难辨认、NPC 缺姓名类别、跨房重载和操作步骤过多进行修改。角色只借鉴外形，不沿用参考角色的姓名、人设或购买行为。

## 操作

- WASD / 方向键支持组合输入和斜向移动，斜向速度归一化，松开一个方向仍继续另一个方向。触屏提供八个方向按钮。
- 碰到家具时沿边滑动，不能穿过阻挡格；点击寻路在空旷位置使用直线路段，绕开障碍时也尽量减少网格折线。
- 店长基础移动速度从 72 调整为 100 导航像素/秒，NPC 保留 72。正式 Host 位置更新间隔从 250 ms 缩短到 100 ms，显示层更快追踪权威位置。
- 点击设施的实际可见矩形可直接走近并打开；保留 E 交互和手账导航入口。
- 点击实体牌桌会自动走近、打开对战界面并选中该桌，省去先到服务台再选桌的步骤。
- 从货架去拆包、从订货切到零售等操作会自动前往正确柜台；不会留下一串旧窗口。仍须到柜台附近才能真正开包、补货或交易。
- 到货订单可“一键签收全部到货”；同组商品可“一键补满货架”，按全店剩余容量补货，放不下或受保护者留在仓库。

## 连续房间

主店与对战房预先绘制在一个 Phaser 世界中，后者展示偏移为 `worldOffset: {x:480,y:0}`。相机、玩家精灵和纹理保留，走过右侧通道后不会销毁或重建场景。可持续按住方向键穿过通道，回来亦然。

后端仍采用各房间自己的坐标和库存权限。出口增加 `seamlessEdge: east/west`，转换只允许在房间边缘 6 像素内发生，目标房间保留纵向位置。前端的世界偏移只用于画面；不能通过填写另一个 roomId 瞬移。原有非连续地图出口仍可用。

关键入口：

| 文件 | 修改职责 |
| --- | --- |
| `frontend/world/movement-view.mjs` | 键盘、触控、组合方向与跨房时保留按键 |
| `modules/backend/navigation.mjs` | 权威向量移动、碰撞、沿墙滑动、直线段检测和路径压缩 |
| `frontend/scenes/world-scene.mjs` | 多房间一次绘制、共享相机和逻辑房间切换 |

| `modules/backend/runtime.mjs` | 真实房间坐标转换、一键签收/补货、旧导航路线恢复 |

## 美术与场景

导航网格继续为 16×16，避免因素材分辨率改变而重写业务距离。角色原生帧从 24×32 重画为 48×64；立绘 128×128；瓦片图像使用 32×32，通过二倍采样映射到 16×16 导航单位。设施在新的 192×192 图集单元中绘制，再以二倍采样显示，尺寸、脚底深度和碰撞由独立元数据描述。新角色的脸部、发束、服装和配饰重新绘制。

主店加入大型陈列架、卡包/卡盒展示柜、进货拆包台、二级市场柜台、回收桶，以及海报、盆栽、时钟、沙发、茶几、奖杯、音箱和公告板。对战房增加牌桌、座椅、服务柜台与休息区。设施上方常驻用途招牌，绘制位置、点击范围、阻挡和站位来自同一地图源。

主画面按店面比例适配，默认尽量看到完整店面；用户仍可在设置中放大镜头。窄屏时画布可随容器缩小，姓名标签保持可读的屏幕字号。

## 美术调整入口

- `tools/frontend-art/characters-v2.mjs`：外观表、各方向行走帧与立绘。
- `tools/frontend-art/props-v2.mjs`：配色、设施原生像素、实际尺寸、深度和阻挡矩形。
- `tools/frontend-art/maps-v2.mjs`：布局、招牌、连续通道、站位、桌位与世界偏移；生成时检查所有交互、出口和座位可达。
- `node tools/frontend-art/build.mjs`：重新生成 `assets/frontend` 当前正式素材。
- `node tools/frontend-art/export-preview.mjs`：导出对照图到 `.local/frontend-v2/art`，不会覆盖上一位模型交付的截图。
- `frontend/world/actor-view.mjs`：角色显示尺寸、姓名/类别、状态和重叠避让。

旧生成器 `characters.mjs/props.mjs/maps.mjs` 保留，供历史样板与基础地图元数据复用；当前正式构建明确使用 `*-v2.mjs`，不要修改旧生成器后误以为正式美术已经改变。

## 接口变化与存档

`world.input` 新增 `vector:{x,y}`，保留原 `direction` 和 `destination`。输入有界且须为有限数值，服务端负责归一化与碰撞。地图增加 `worldOffset`、`signs` 和出口 `seamlessEdge`。角色清单增加 `displayScale`，瓦片清单增加 `frameSize`，设施清单增加 `artScale`，渲染必须区分原生图像像素与导航单位。

新增命令 `supplier.receiveAll` 返回 orders、inventoryRefs 和 stock；`retail.listAll({inventoryRefs})` 返回 listed、remaining 和 note。两者继续沿用事务、站位校验和 requestId 幂等保护。

没有清空存档。旧位置位于新家具内时会迁到附近可走位置，导航版本改变时会重建未完成路径；卡片、钱包、盒内既定内容和档案分支保留。

该版本仍使用有限的四向朝向动画来表现连续方向移动；后续可独立扩展八方向动画，不影响移动协议和经济规则。

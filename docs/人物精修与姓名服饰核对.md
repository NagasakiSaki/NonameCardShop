# 人物精修与姓名服饰核对

2026-10-24。范围：用户确认的五团共 25 人，外形参考与 NPC 身份分离。原有顾客国际化姓名、预算、卡牌和关系不因换皮变动。本轮只更新工程，未重建 exe 或清空玩家存档。

## 本轮修复与重新绘制

脸部消失的真实原因是浏览器复制 ImageData 时使用对象展开，丢失了原型上的 width / height，头部图层因此没有被合成。Node 的普通对象导出不受此问题影响，所以只验导出图会漏检。本轮显式复制尺寸与数据，完整立绘的后发层也采用同样处理；增加浏览器和 CLI 对所有像素的哈希一致性检查。

额外修复：正面/侧面的眼睛与嘴最后绘制，背面保持后脑；选择外观自动停下并朝正面；窄窗口保留对话立绘和至少 1x 原生地图，局部横向滚动。正式地图最小缩放也为 1x。

25 人完整立绘是新画的身体与服饰，复用已署名的面部/头发部件，原生 **128×224**；列表头像是从立绘 (16,14) 裁出的 **96×96**，不是把全身缩成头像。地图仍是认可的 LPC **64×64、四向×八帧**，图集 512×256、9fps、落脚点 (32,61)。本轮补足各人物的裙裤、披尾、袖型、格纹、腿装、鞋与发饰。

## 实现入口与生成结果

- 完整立绘：experiments/character-art/standing-portrait.mjs，每团独立服装绘制；调衣色时保留皮肤和发色。
- 行走补绘：experiments/character-art/pixel-customization.mjs，沿用原步态，按帧头部位置贴发饰与五官。
- 参数注册：data/band-appearances.mjs、data/character-audit.mjs。外观字段不能用于推断贫富/偏好。
- 安装器：tools/frontend-art/character-pack.mjs；manifest 分别提供 portrait / avatar / sheet，使用内容哈希以避旧缓存。
- 游戏内：设置的列表头像和所选完整立绘、街坊页面的实际外观立绘；顾客与店长的四向行走。
- 完整立绘：experiments/character-art/generated/bd-*-standing-128x224.png；分团图册：*-standing-lineup.png。
- 预览：[人物试验室](http://127.0.0.1:5190/experiments/character-art/index.html)，[完整图册](http://127.0.0.1:5190/experiments/character-art/generated/gallery.html)。跨模型操作读 [MODEL-GUIDE.md](../experiments/character-art/MODEL-GUIDE.md)。

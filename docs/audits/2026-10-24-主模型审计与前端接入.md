## 1. 覆盖与方法

静态盘点基线 Git 共 17,358 个跟踪文件；排除 vendor、tools/_chars、桌面生成源后的代码/配置/HTML/CSS/类型等文本输入为 316 个。按入口读调用链，同时对输入做 JSON 可解析、本地静态 import 存在性扫描。扫描包括上游抽取样本和工具 Acorn，不把它们误称全部为自有代码。

| 区域 | 深度与实际范围 |
| --- | --- |
| `modules/backend/` | 深入跟踪 runtime 队列/事务、报价/购物篮、采购/密封内容、市场与流通、垃圾桶、任务奖励、NPC 访问/牌桌/模拟、熟客托管、日结/存储/档案/配置与查询；其余常量/外观入口静态核对 |
| `frontend/`、`frontend-next/` | 深入默认启动、主菜单/换档、外壳/手账、窗口暂停、真实操作恢复、交易/经营绑定、垃圾桶、旧经营入口；其余展示/Mock/回退组件做入口和引用核对，未重新逐帧验全员美术 |
| `integration/` | 跟踪 Host 建立/时钟、玩家挂载/中断/事件来源、NPC 后台调度、引擎 HTTP 边界、BO3/KOF 换将/初始手牌/结果桥接。定向生命周期检查，不声称重测所有技能组合 |
| `server.mjs`、`dev/` | 审查静态路径/引擎服务、端口失败与回滚、开发入口/启动复用、构建与安全发布；服务定向测试通过，未重做安装环境 |
| `desktop/` | 深入主进程、菜单存档/备份、导入/导出、退出服务和 Electron 资源过滤；通过真实 Electron 隔离 profile 测试，未生成或验证新安装包 |
| 根级旧页面、`modules/*.js` | 明确 `/legacy.html` 与当前根入口/回退路径差别，核对脚本和旧桌面测试假设；未完整重玩旧经营数值，不能把旧变量当新版数据 |
| `tools/`、`data/`、素材与 contracts | 盘点生成/抽取/资产/版本/发布链，核对当下 API/站位和构建输入；本轮不重建所有素材、不再次全量模拟抽卡。规则与资金相关定向回归通过 |
| `tests/` | 核对测试组/默认与旧入口假设，补当前界面与当前桌面路径。只执行本轮风险相关检查，未运行整个 npm test |
| `vendor/noname` | 第三方完整性与接入边界检查：15,876 文件、1,340,042,134 字节 SHA-256 通过；排除 450 个上游 Home 用户配置/缓存。没有逐行人工审阅全部上游源码 |

盘点细项：`.local/hq-audit/inventory.json`；基线复现：`.local/hq-audit/baseline-observations.json`。这些均为本地诊断，不含玩家进度，不整包发布。

## 3. HQ-DEV 已完成的复杂前端

- **经营操作台**：设施等级/费用/真实效果、员工雇佣与当班/休息及合同工资、熟客立绘/交谈/寻卡申请/出售实物/交付/取消、采购待办。采购签收继续去原交易台，不复制结算。
- **卡面垃圾桶**：按卡种/印刷分组并显示数量与来源，可看卡面/技能、展开实物副本、单张或全部拾回、选择自己的收藏卡丢弃。分页读取全部数据、卡组分页、实物按需展开；保护/占用不会当可丢弃。
- **恢复与站位**：升级、员工、熟客操作和垃圾桶复用现有 requestId/未知结果补查/原号重试。关闭再开可补查；读档后旧选择/异步结果失效。导航去柜台，不让按钮绕过站位。
- **生命周期**：经营窗口重新渲染先销毁旧订阅/组件；手账查询不重入，换档/销毁后的返回不更新旧界面；返回主菜单后手账按钮恢复正常。
- **引导**：总结步骤进日报，认识熟客进熟客页，原有活动/报价/任务口径保持。

FAST-02/03 在审计后段交付，主模型进一步补完共用人物模板并正式接入 21 人精修和 32 个升级/当班状态；纠正源图误判与保留范围见 [第二批素材记录](../人物行走与设施升级第二批.md)。四人基线和 25 人正式源立绘哈希保持。

默认入口采用新经营/垃圾桶；`?tradeUI=previous`、`?tradeUI=classic` 保留旧页面回退，并继续共用真实存档。回退也不能绕过后端新增的单卡交付站位检查。

维护文件：`frontend-next/components/management/operations.mjs`（纯展示）、`screens/management.mjs`（正式绑定）、`screens/trash.mjs`（卡面桶）、`desktop/save-bridge.cjs`（渲染进程存档适配）。现有 UI/Host 协议不另起版本，新增限制说明写入 contracts/README。

## 审查后修正

1. **交易页串页。** 候选 CSS 覆盖了 hidden，导致三个工作区同时出现。正式版显式隐藏非当前页。
2. **同主题整盒误选。** 整盒快开默认只选一盒；“全部散包”默认不拆盒，勾选包含整盒才纳入。改变路径/商品时清除旧实物范围。
3. **分支失效判断。** 候选先替换 view 再比较 branch，判断永远相等。正式版先保存旧身份，读档后清理旧预览/选择，过日清旧报价。
4. **操作号与未知结果。** 改用 UUID；拆盒传回同一 requestId；补上留一上架的查询/原号重试。关闭再打开保留本分支草稿及已结算的开包结果，旧分支未决状态不能阻塞新交易。
5. **统计口径。** 删除“模拟对局不计入”的错误说明，模拟场次另列。C 的访问结果使用购买、比赛、拾牌、未成交、技术中断五种互斥结果，不强行套“进店=成交+流失”。
6. **暂停与收尾。** 按真实暂停原因 code 区分窗口暂停和手动/后台暂停；准备期等待开门、打烊和离店收尾不冒充技术卡死。
7. **旧字段适配。** 订单 dueAt 转为日期时间；金额、授信、挂牌数量、任务列表按真实结构适配；移除演示费率、占位源码承诺与开发备注。
8. **采购站位被挡。** 候选额外箱架位于 (296,232)，会挡住采购站位。采用替换原箱堆位置的方案；新地图保留语义 ID，并通过交互点/出口/牌桌座位可达检查。
9. **素材可重建。** 四人走路修复进入浏览器与 CLI 共用的渲染入口；正式立绘仍由用户图源覆盖。新增设施进入 props 管线，不依赖候选 PNG；正式人物包不再额外发布未使用的旧几何立绘。
10. **Windows 构建写入。** 构建期间遇到 JSON 文件临时占用，清单/地图改用完整临时文件加原子替换与有限重试，避免留下半份元数据。

## 后端补充

- `snapshot.storefront` 是只读场景投影：货架密封商品量、设施等级、牌桌空闲/预留/对战/结束状态。货架和桌面贴图按此变化，不由动画结算。
- `snapshot.wallet.supplierCreditAvailable` 为权威剩余授信。
- `management.insights.departures` 保留最近 20 次有记录的离店信息，包含访问 ID、结果与原因。
- 新日观察记录采购现金净支出/授信、任务现金到账/抵欠拆分，不依赖被截断的最近流水反推。旧日缺字段保持未知，不回填假零。
- 日报库存列明确为“今日销量”，没有把今日记录冒充近三日预测；实际成交、资金、强度、稀有度均来自现有规则。

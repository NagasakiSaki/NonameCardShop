## 直接预览

[新交易样稿](http://127.0.0.1:5190/frontend-next/experiments/card-trade/index.html)。现有启动器提供此页；不用重新安装软件。原人物预览和正式前端仍可使用。

单卡市场以原画为主体，卡格直接显示稀有度、×持有、价格和市场库存；点选后右侧看交易信息，大图弹层看完整技能文字。窄屏详情使用弹层。收藏模式支持单张/重复牌模拟上架，上架不直接产生收入。

## 人物工具给其他模型的入口

```powershell
node tools/character-kit/cli.mjs list-parts --json
node tools/character-kit/cli.mjs validate --config experiments/character-art/generated/appearances.json --json
node tools/character-kit/cli.mjs contact-sheet --out .local/character-kit/review --json
node tools/character-kit/audit.mjs --out .local/collaboration/QA-01/new-review --json
```

CLI 的 JSON stdout 只有一个对象，校验错误带字段路径；源码目录、资源目录、越出工程的路径以及指向它们的目录链接都不能作为输出。已有目录默认拒绝，显式覆盖也只接受带本工具标记的目录。工具不自动渲染/安装正式人物包，不安装依赖或请求 API。

详细参数：[character-kit README](../tools/character-kit/README.md)；绘制规范：[MODEL-GUIDE](../experiments/character-art/MODEL-GUIDE.md)。图册保留姓名顺序、稳定 ID、原生尺寸和署名入口。

## 数据与接口边界

UI-01 的价格、稀有度、余额、库存均为演示值，不能用于正式经济设计。金额使用整数分作为样稿输入；正式接口的货币单位仍按 Host 返回。卡面和技能描述引用原有卡库；技能源代码尚待真实 detail 接口提供。

`frontend-next/components/trade.mjs` 是纯展示组件，控制器仅在内存中模拟交易；没有新增真实的采购报价、批量交易、暂停令牌或 v2 DTO。本批没有把“Mock 能跑”写成“正式功能已完成”。

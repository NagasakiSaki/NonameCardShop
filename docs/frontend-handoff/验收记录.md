## 4. 美术自评（人工目检结论）

- 角色为原生像素绘制，四向 12 帧，落脚点一致；行进时裤腿收放 + 抬脚 2px + 摆臂，撞墙立即停步，不做上下晃动冒充行走。
- 七套角色靠装备/发型/肤色区分：鸭舌帽、银发与眼镜、头带与牌盒、高马尾与发夹、宽檐帽与收藏箱都在 2× 下可辨认。
- 统一左上光源：左侧提亮、右侧压暗、贴地一行环境遮蔽；家具与角色都按脚底 y 排序，柜台不再整层压住角色。
- 已知仍不满意：立绘只有七种表情、没有头部微倾；对战房家具偏少（两桌 + 四椅 + 服务台）；道具只有 16 件。这些是首版样板，按脚本参数可继续扩展。

## 5. 正式 Host 模式

`?mode=host` 会动态导入 `/integration/frontend-host.mjs`。在本工作区当前版本上实测：

- 连接成功，返回 `clock={day:1,minute:480,phase:'preparing'}`、`wallet.available=1200`，`battle.mount` 存在。
- 场景用本包的 `assets/frontend/maps/*.json` 渲染，受控角色被正确识别（`actorId='player'`）并进入相机跟随。
- 界面读取到后端真实任务（第一次进货 / 签收三包卡 / 自己开一包 …）。
- 控制台业务错误 0（图片 404 由缺图占位兜底）。
- 形状差异（`tasks.list` 裸数组、`actorsUpdated` 直接数组、`management.*` 返回 `available:false`）已按 `接口缺口.md` 归一，**未修改任何后端文件**。

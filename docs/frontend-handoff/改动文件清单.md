# 改动文件清单

**允许目录外零改动。** `git status --porcelain` 只显示：

```text
?? assets/frontend/
?? docs/frontend-handoff/
?? frontend/
?? tests/frontend/
?? tools/frontend-art/
```

（`docs/美术与前端独立开发交接文档.md` 的修改来自交接方，不是本包产生。）

开发期间后端模型在同一工作副本里并行推进，工作区还会看到 `modules/backend/**`、`integration/**`、`data/backend-*.json`、`tests/run.mjs` 等改动与新增文件。**这些都不属于本包**：本包只新增上面五个目录，没有编辑、格式化或删除任何后端文件；提交时只应包含这五个目录。

未修改：根 `index.html`、`app.js`/`shop.js`/`business-ui.js` 等旧业务脚本、`modules/**`、`data/**`、`contracts/**`、`integration/**`、`server.mjs`、`dev/**`、`desktop/**`、`vendor/**`、`package*.json`、根 `tests/**`。

## frontend/（新入口与界面）

| 文件 | 职责 |
| --- | --- |
| `index.html` | 唯一入口；加载本地 Phaser（`../vendor/phaser/phaser.min.js`，只读）与 `main.mjs` |
| `main.mjs` | 解析 `?mode/fixture/scene`、连接 Host、启动外壳、错误页与重试 |
| `app-shell.mjs` | 总装：场景、相机缩放、HUD、手账、窗口调度、交互路由、事件与序号缺口重同步 |
| `host/host-loader.mjs` | 唯一 Host 入口；Mock/正式工厂、`contractVersion` 校验、稳定 `clientId`；正式缺失只报错 |
| `host/normalize.mjs` | 把列表类查询（`{items}` / 裸数组）与任务字段（`goal`/`target`）归一，业务值不推导 |
| `host/contract-types.d.ts` | 契约 `card-shop-ui/1.0` 只读类型镜像，不参与运行 |
| `scenes/world-scene.mjs` | Phaser 场景：瓦片烘焙、家具排序、角色、光层、相机边界与整数缩放 |
| `scenes/store-scene.mjs` / `battle-room-scene.mjs` | 两张地图的场景入口 |
| `world/map-loader.mjs` | 素材清单与地图 JSON 读取、路径解析、就近交互点与出口判定 |
| `world/actor-view.mjs` | 角色精灵、四向动画、插值、阴影、靠近才显示的名牌 |
| `world/movement-view.mjs` | 键盘/触屏/点击 → `host.world.input`；失焦清键 |
| `world/lighting-view.mjs` | 按 Host 游戏分钟插值环境色与灯光强度 |
| `world/interaction-router.mjs` | 交互提示、先走位再交互、出口触发 |
| `ui/window-manager.mjs` | 窗口栈、绑定暂停令牌、Esc 关闭最上层、嵌套清理 |
| `ui/components.mjs` | DOM 构造、金额/时间格式化、三态、错误视图、提示条、列表归一 |
| `ui/hud.mjs` | 顶部 HUD 渲染与入口按钮 |
| `ui/inventory.mjs` | 背包：搜索/稀有度/筛选/分页/详情入口/留一上架预览 |
| `ui/card-detail.mjs` | 卡牌详情：印刷稀有度 vs 当前分级、技能与源码折叠、持仓与准入原因 |
| `ui/supplier.mjs` | 订货、报价、下单、签收、零售货架 |
| `ui/opening.mjs` | 开包预览→执行→逐张/只看 SR+/汇总；结果未知时按同一 requestId 补查 |
| `ui/secondary-market.mjs` | 买卡/我的出售/收购报价/行情记录；报价确认后才成交 |
| `ui/combat-room.mjs` | 桌位、配队、倍数与费用确认、报名、`battle.mount` 挂载区、认输 |
| `ui/tasks.mjs` / `day-report.mjs` / `day-saves.mjs` | 任务引导与领取、日报分项、按天存档 |
| `ui/management.mjs` / `settings.mjs` / `trash.mjs` / `help.mjs` | 设施员工街坊（含收卡申请与预约交付）、前端偏好与开发配置、垃圾桶捡回、店主手册 |
| `styles/tokens.css` | 色板/字号/间距变量，色值与 `assets/frontend/manifest.json` 的 palette 同源 |
| `styles/layout.css` / `components.css` | 布局与组件样式（含 `[hidden]` 兜底、像素画抗锯齿关闭） |
| `mock/mock-host.mjs` | 与正式 Host 同形的演示实现：查询/命令/事件/暂停/移动/挂载/幂等 |
| `mock/fixtures/cards.mjs` | 读取 `/data/cards.json` 生成演示 DTO（含演示分级阈值，非正式规则） |
| `mock/fixtures/fixtures.mjs` | 10 个固定种子场景定义 |

## assets/frontend/（新素材）

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | 素材清单：帧尺寸、锚点、方向行序、idle/walk 列序、瓦片/道具索引、地图路径、色板 |
| `characters/*.png` | 七套 72×128 行走图集（3 列 × 4 行） |
| `portraits/*.png` | 七张 96×96 立绘 |
| `tiles/tileset.png` | 128×32，8 列 × 2 行，13 块 16×16 瓦片 |
| `props/props.png` | 192×192，4×4 个 48×48 单元，16 件家具/道具 |
| `fx/glow.png` `fx/shadow.png` | 灯光叠加层与角色脚下阴影 |
| `maps/store.json` `maps/battle-room.json` | 地图、碰撞、可通行表、出口、交互点、排队点、桌位与座位、灯位 |
| `fonts/` | 空目录占位：UI 使用系统中文字体栈（见 manifest `ui.fontStack`），不打包字体以避开授权与体积问题 |

## tools/frontend-art/（美术源与生成工具）

| 文件 | 职责 |
| --- | --- |
| `png.mjs` | 零依赖 PNG 编码（filter=0）与自检用解码器 |
| `pixkit.mjs` | 画布、调色板、确定性噪声、描边、整数量化放大 |
| `characters.mjs` | 七套角色的四向 12 帧与立绘绘制（含表情分化、肤色、迈步帧表） |
| `props.mjs` | 瓦片集、家具与道具、灯光晕、阴影 |
| `maps.mjs` | 两张地图布局、家具碰撞写入可通行表、交互点/出口/座位、可达性校验 |
| `build.mjs` | 生成 `assets/frontend` 全部素材与清单（可重复执行） |
| `export-preview.mjs` | 导出人工目检对照图 |
| `probe-host.mjs` / `probe-perf.mjs` | 正式 Host 连接冒烟、帧率与负载实测 |

## tests/frontend/（独立检查，不改根测试入口）

| 文件 | 覆盖 |
| --- | --- |
| `assets.mjs` | 图集尺寸整除、帧/列序声明、透明底、清单路径、地图图层长度与索引、出生点与交互可达、出口双向匹配、座位不重叠、道具碰撞矩形 |

| `ui-smoke.mjs` | Chromium 实机：启动、四向行走、点击寻路、背包→详情嵌套、报价下单、开包、市场、对战房、各窗口、令牌释放、黄昏/异常/2563 条/窄屏 |
| `run.mjs` | 三个套件的统一入口 |

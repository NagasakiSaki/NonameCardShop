# 素材说明

## 1. 生成方式

全部场景素材由脚本逐像素计算生成，不依赖任何绘图库、不联网、不使用文生图或缩放位图：

```bash
node tools/frontend-art/build.mjs            # 写 assets/frontend/**
node tools/frontend-art/export-preview.mjs   # 写人工目检对照图（screenshots/art-*.png）
node tests/frontend/assets.mjs               # 12 项素材/地图自检
```

- 运行环境：Node.js v24.15.0（项目根 `engines: node >= 22.12`），零新增依赖。
- PNG 由 `tools/frontend-art/png.mjs` 自行编码（filter=0，RGBA8），确定性输出。
- **源文件就是生成脚本**。手改 PNG 会被下一次 `build.mjs` 覆盖；要改画面就改参数并重跑。
- 修改入口：
  - 角色外形/配色/表情 → `characters.mjs` 的 `CHARACTERS` 与各 `draw*` 函数
  - 瓦片/家具/灯光晕 → `props.mjs` 的 `TILES`、`PROPS`、`PROP_META`
  - 房间布局/交互点/桌位 → `maps.mjs` 的 `makeGrid` 参数与 `*_PROPS`、`interactions`、`exits`

## 2. 规格

| 项目 | 规格 | 备注 |
| --- | --- | --- |
| 基础瓦片 | 16×16 | 瓦片集 128×48（8 列 × 3 行），共 17 块（含四角墙角与侧墙门） |
| 地图角色 | 24×32 / 帧 | 图集 72×128；3 列 × 4 行 = 12 帧 |
| 方向行序 | 下 / 左 / 右 / 上 | `directions: {down:0,left:1,right:2,up:3}` |
| 帧序 | 迈左 / 待机 / 迈右 | 待机固定第 1 列；行走按 0→1→2→1 循环 |
| 锚点 | 帧内 (12,30) | 物理坐标指向地面落脚点；12 帧落脚点一致 |
| 立绘 | 96×96 | 48×48 逻辑网格 ×2；同发型/同服装/同肤色/同标志物 |
| 家具道具 | 48×48 单元 | 图集 192×240（4 列 × 5 行），18 件；每件声明 `w/h/footY/occludes` 与碰撞矩形 |
| 房间 | 30×20 格 = 480×320 原生像素 | 相机整数倍 1×/2×/3×，关闭抗锯齿 |
| 光效 | `fx/glow.png` 96×96、`fx/shadow.png` 20×10 | 灯位坐标写在地图 `lights` |

地图 JSON 关键字段：`mapId`、`navVersion`、`tileSize`、`width/height`、`layers[{floor,walls}]`、`props[]`、`walkable[]`、`spawn`、`exits[]`、`interactions[]`（`anchor`/`stand`/`radius`）、`queuePoints[]`、`tables[].seatAnchors[]`、`lights[]`。所有位置都是地图原生像素，不含屏幕坐标。

## 3. 色板

定义在 `tools/frontend-art/pixkit.mjs` 的 `PALETTE`，同值同步到 `frontend/styles/tokens.css`，并写进 `assets/frontend/manifest.json` 的 `palette`。

| --- | --- |
| 描边 | `#20182a` / `#3a2d47` |
| 肤色（4 档） | `#f9ddbc` `#e5ac7c` `#cf9764` `#a2704a`（各带亮/暗） |
| 头发（6 系） | 棕 `#8a5230`、黑 `#2d2637`、金 `#e9c67a`、红 `#b05138`、银 `#cbd0dc` |
| 衣物（9 系） | 红 `#c2503c`、蓝 `#3d5c96`、绿 `#4a7654`、芥黄 `#c19a48`、紫 `#6a4988`、米 `#e8dfc8`、灰 `#8b8b98`、青 `#3d7a78` |
| 木质 | `#9a6f4a` / `#b98a5f` / `#74502f` / `#573a24` |
| 墙面 | `#e4d7ba` / `#c3b294` / 墙裙 `#8a6242` |
| 地毯 | `#7c3f4a` / `#9a5058` / 金饰边 `#e0c98c` |
| 金属/玻璃/金/叶 | `#b8bec9`、`#9fd2da`、`#e8b64a`、`#4f8757` |

每张角色图集实际使用 24–32 种颜色，立绘 15–24 种（`tests/frontend/assets.mjs` 会打印统计）。同色板保证了角色、家具与 UI 是同一套观感。

## 4. 角色与视觉区分

七套角色共享身体骨架（文档允许），靠轮廓、发型、装备和肤色区分，不是换色：

| id | 名称 | 可辨识特征 |
| --- | --- | --- |
| `owner` | 店长 | 帆布围裙、胸前店徽、腰间钥匙、绿衫 |
| `rookie` | 新手顾客 | 绿鸭舌帽 + 帽檐、手拎入门牌盒、浅肤色、大圆眼 |
| `collector` | 收藏家 | 银灰长发及肩、圆框眼镜、金边外套、腋下收藏册 |
| `competitor` | 竞技玩家 | 红色头带、运动短裤露腿、腰侧牌盒、小麦肤色 |
| `passerby` | 路过顾客 | 深肤金发、短袖、布拖鞋，无随身物 |
| `regular` | 熟客 | 高马尾 + 发夹、米色围巾、弯眼笑 |
| `bigspender` | 高预算顾客 | 宽檐礼帽 + 金帽带、亮面高领外套、手提收藏箱 |

立绘另有七种表情（平静 / 大眼 / 细长眼 / 挑眉 / 标准 / 弯眼 / 半垂眼），与地图角色同一发型与服装。

## 5. 地图与交互点

| 地图 | 必需要素 | 已放置 |
| --- | --- | --- |
| `store` | 入口、零售货架、进货/开包柜台、二级市场柜台、垃圾桶、去对战房的门 | 入口地垫 (14,17)；三组货架 + 封包/封盒陈列；蓝色服务柜台 (17,13)；紫色单卡柜台 (22,4)；垃圾桶 (27,17)；右墙门 (29,9) |
| `battle-room` | 出入口、两张牌桌、等候点、报名点 | 左墙门 (0,9)；1 号桌 (6,5)、2 号桌 (17,11)；排队点 3 处；服务台 (22,3) |

家具清单（18 件）：零售柜台、服务柜台、单卡柜台（kiosk）、货架、封包陈列、封盒陈列、收银机、垃圾桶、双人牌桌、椅子、长椅、灯具、招牌、告示板、地毯、绿植、箱堆、门垫。

`tests/frontend/assets.mjs` 会验证：出生点可走、交互站位与出口可达、出口双向匹配、座位不重叠、道具碰撞矩形在精灵范围内。

**门口不死循环的硬约定**：出生点与出口保持至少 2 格（约 48px）距离，交互路由另带 900ms 出口冷却；换图落地不会被对面门口弹回。

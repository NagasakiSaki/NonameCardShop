# 下一位全面优化模型接管包

日期：2026-10-27。用途：让接手模型理解当前游戏后有序优化，避免误用历史需求或再次全盘覆盖。

## 交给模型的方法

1. 将 `启动指令.txt` 的内容作为你发给模型的指令。
2. 同时提供本文件夹和工程访问方式；本机工程为 `D:\GameDev\NonameCardShop`。远程模型可从公开仓库获取代码和 LFS 素材，用稳定标签定位运行基线。
3. 要求它先读 `全面优化开发总文档.md`、`任务清单.json` 和 `核查快照.json`，随后在授权范围内分阶段实施并交付。

只把本文档或截图发给没有工程访问能力的模型，不能期待它验证真实实现。真实玩家存档不需要作为接管附件。原图和本机候选不在公开仓库时，用独立配置路径提供，不整包上传个人电脑目录。

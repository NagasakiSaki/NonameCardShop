# 无名卡店 v0.8.2 · Windows x64

## 安装与启动

下载 `NonameCardShop-0.8.2-Setup-x64.exe`，双击安装，从桌面「无名卡店」启动。安装包包含 Electron 45.0.0、游戏资源及无名杀 v1.11.6，不需要自行安装 Node.js 或启动命令行服务。

更新保留 `%APPDATA%\NonameCardShop` 中的资料；浏览器开发版与安装版的存档相互独立。已有新版世界档案可在「存档」菜单导出/导入。正式安装版使用本机 51740/51741 两个端口。

## 本版内容

- 明亮二次元卡店场景，保留五团 25 位角色、用户图源立绘、细化设施和卡面界面。
- 优化镜头跟随和地板缓存，减少行走时的地砖采样抖动；新增独立四向站姿，伙伴到岗后正面站立。
- 伙伴新增「约战赚钱（有输赢）」岗位：主动邀请顾客下注打牌，后台模拟、不暂停营业；本金托管、每日风控与收支流水。
- KOF 三将接力（换将重新摸四张）、斗地主换边 BO3、2v2 BO3；公开备战池、收藏置顶、按当前模式评分选将。
- 固定发行稀有度与卡盒定额、进货/售货/拆包、NPC 拆包弃牌与拾牌、SR/SSR 二级市场。
- 高手挑战逐日顺延、招募伙伴、设施升级、按天回到当天开店时、海玲借款阶段目标。
- 补全技能描述中的上游术语、解释和动态提示；大库存使用虚拟网格，保留滚动位置和真实实物引用。

上述经营与界面内容同步此前持续更新的源码开发版。源码回归 83 项已通过（含失败补跑），具体记录见[本轮验收](../reviews/2026-10-27-行走采样待机与伙伴约战.md)。桌面安装与运行验证记录见[本版本发行验收](v0.8.2-验收.md)。

## 注意事项

这是仍在开发中的游戏原型。伙伴牌局当前采用后台 KOF 模拟；户外探索、炒卡交易所与新镀层玩法仍为后续扩展。缺失的部分卡图保留占位。安装包未配置自动更新，也未附发布者数字签名。

## 可以试玩的流程

进入开发版点 HUD 的“故事”。新档默认开启；旧档点“开启街角故事”后进入序章。读完后进入第一章，经营等待会关掉剧情窗口，回到店内真实上架、开门、等顾客付款。成交后“故事 · 可继续”提示续读，接着选择收藏/切磋方向，解锁林澄、许遥、周野三条短支线。

阅读、选择暂停经营，等待条件释放该窗口暂停。自然销售、真实业务指标触发续接；没有向正式世界注入测试销量。没有剧情金钱奖励或伪造考核资格。人物使用现有立绘联系人展示，没有额外生成实体 NPC。

## 实际完成的基础

- 制作源、浏览器与 Node 共用校验定义；内容编译、SHA-256、显式能力依赖、不可变修订与活动版本索引。
- 同一 Host 事务内运行、效果回执、已知失败快照恢复、请求幂等和结果未知核对；没有嵌套异步 Host.command。
- 多会话等待独立记录真实事件，不依赖会截断的展示日志；经营证据与真实玩家牌局证据分开。
- 剧情游标/旗标/回执跟随手动档、日初档和导入档；分支变化不能绕过去重。旧剧情包按 hash 加载，缺内容保留进度并允许继续经营，未知未来状态不重置。
- 复用 WindowManager 暂停、已有立绘、手机与桌面分页；关闭旧分支的窗口不会修改恢复后的同 ID 会话。

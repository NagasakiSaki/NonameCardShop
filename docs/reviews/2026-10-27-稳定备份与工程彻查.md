## 性能观察

同一机器 Node v24.15.0，模块预加载后，交替运行原稳定版和整理版各三次。场景仅为隔离内存仓库的 `createRuntime + connect`，没有浏览器渲染，也没有操作真实存档。

| 版本 | 三次耗时（毫秒） | 中位数 |
| --- | --- | --- |
| 原稳定版 | 2899 / 2436 / 2449 | 2449 |
| 整理版 | 912 / 825 / 754 | 825 |

收益来自复用相同规则下的武将目录。这个结果不能推导整页启动提升相同比例或游戏达到某一帧率。报告原始样本已随验证汇总保存。

## 保留的问题与后续工作

- 本地上游缺少 43 张目录所指向的武将原图，其中在售主题 21 张、停产主题 22 张；没有同名其他格式或旧图副本。具体 ID 在 [缺失卡图清单](2026-10-27-缺失卡图清单.json)，继续显示缺图占位，未挪用其他武将图片。补图需有确认过的对应图源。
- 原生引擎以其完整 manifest 校验，动态技能、音频和非在售武将不能因静态零引用裁掉。自然对局中的个别上游资源请求仍可能 404，需要按具体请求补来源，不能只凭启动通过宣布素材齐全。
- 复杂技能收益仍需逐技能校准；目前标记、发行和理论评分相互独立，本次没有为了清理结构重算玩法。
- 旧试玩入口和显式旧交易 UI 仍被兼容检查使用，保留可定位边界；不靠大规模改名制造整洁。当前千行滚动检查通过，后续数据量继续增长时，应先测输入和绘制开销，再决定是否虚拟化列表。

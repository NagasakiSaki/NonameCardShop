# 当前开发版本公开发布

2026-10-26，经用户明确要求，将原私有仓库 `NagasakiSaki/NonameCardShop` 改为 public。地址：https://github.com/NagasakiSaki/NonameCardShop 。GitHub API 返回 `private:false`、`visibility:PUBLIC`，匿名仓库与当前 README 请求返回 200。

公开范围是已提交的当前开发版本及过滤后的既有标签/历史；不包含尚未接入的前端模型候选、用户存档、`.local`、AI 工作目录或上游 `vendor/noname/Home/` 浏览器用户数据。发布继续使用过滤副本，禁止直接从原始含缓存历史推送。

根目录添加 GPL-3.0 LICENSE，沿用现有 package.json 的 GPL-3.0-only 声明。无名杀许可保留；第三方卡面、人物、音频、字体和品牌没有被重新授权，见 THIRD_PARTY_NOTICES.md。公开不代表已更新 EXE，也不代表待制作的明亮场景已经上线。

公开前使用官方 Gitleaks 8.30.1（核验下载校验和）扫描过滤副本全部 refs 的历史，并扫描新增暂存内容。11 个命中逐项复核为任务奖励标识、技能 ID、引擎序列化类型标记；只将其精确 fingerprint 登记为误报，不忽略整目录。登记后最终历史扫描通过，完整私有扫描报告留在 `.local/security-tools/`，不发布。

另核对全部 refs 没有被排除的本机数据路径；仓库无既有 release、Actions run 或 Actions artifact。此检查用于本次发布，不是对任意后续提交的永久保证。

公开仓库维护使用 `npm run publish:public`，入口 `dev/publish.mjs --public`。原 `publish:private` 保留兼容且拒绝公开目标；两个命令都会核对远端可见性，导出时排除上游浏览器缓存。已验证 public 命令对 private 目标拒绝，避免误用。

README 已改为当前三赛制、滚动交互和源码启动流程，旧 README 留在 docs/archive。此次仅改发布维护和文档，不修改游戏规则，不接入候选美术。

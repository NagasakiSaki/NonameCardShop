# OPT-14 日档策略拆分

日期：2026-10-27。实施前依赖图和切分方案已在 `64ef1196` 提交，见 [阶段 C 实施边界](../architecture/阶段C-后续实施边界.md)。

`modules/backend/archive-policy.mjs` 接收原来的 catalogFor、navigation、now，将 Runtime 中原有 archive/saveArchive 函数原样移入。负责可信待处理事件的快照折算、整场耗时、日初分支筛选和容量保留；调用方依然在同一个 fork 中执行。`createRuntime` facade、串行事务、唯一 commit、回执、通知顺序、规则初始化和浏览器存储均保持原结构。

定向验证通过：day-starts（日初回退/分支/压力保留）、storage-archives-browser（原子冲突/不可变日档）、narrative-runtime（剧情奖励回滚/幂等/内容版本）、three-formats（费用/卡锁/整场耗时）。没有因此再建立第二套存储或重新发奖励。

本项选择一个可回滚单元完成维护边界，不为行数继续拆所有 reducer 或 UI 外壳。最终跨结构完整回归另记结果；回滚使用本项提交的 git revert，不用覆盖实际玩家数据库。

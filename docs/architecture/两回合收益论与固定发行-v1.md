# 两回合收益论、固定发行与分包选将

更新：2026-10-27。只更新源码开发版，现有卡牌、已封装包盒和存档进度保留。

## 玩家行为

选将先展示卡包入口，进入主题后按当前模式评分降序排列。另有“全部武将”和“收藏武将”入口；收藏不打乱评分顺序。跨包共享已选名单，顶部选中条可取消，确认按钮固定在窗口底部。选中/取消、查看技能和收藏操作保留滚动位置；返回同一卡包保留浏览进度。

整场备战阶段按 KOF、斗地主综合、2v2 分排序。斗地主当局确定阵营后，按地主/农民对应分数重新排序。KOF 接力顺序仍按玩家点击顺序，浏览排序不改写已确认的接力名单。

同一武将版本的多张副本合并显示数量；不同技能版本不合并成一个武将。已有停产主题卡仍可在所属主题中选择，但不恢复该主题进货资格。

## 场景和计分

模型版本 `ideal-two-round-1`。按用户要求，将“两回合”解释为两个完整轮次：

| 条件 | 每轮 | 两轮合计 |
| --- | --- | --- |
| 己方正常摸牌 | 2 张 | 4 张 |
| 己方基础输出 | 造成一次 1 点伤害 | 2 次、共 2 点 |
| 回合外基础受伤 | 受到一次 1 点伤害 | 2 次、共 2 点 |
| 初始手牌 | 起始 4 张 | 不重复发牌 |
| 比较基准 | 相同身份的四血白板 | 地主原生增益在同身份基准中抵消 |

计相对白板的**额外收益**。所有武将共享的正常摸牌、基础伤害和基础受伤不重复记分，也不把“造成伤害后”中的触发条件误当额外伤害。

```text
两轮等效牌收益 CE
  = 净牌差 + 2 × 技能净血差 + 2 × 初始体力差
    + 少量强中奖励 + 少量装备破坏奖励

场景分 = clamp(50 + 5 × CE, 0, 200)
```

- 己方获得一张：牌差 +1；敌方失去一张：牌差 +1。
- 从敌人处偷一张：己方 +1、敌方 −1，合计 +2。
- 自己弃一张、敌人弃一张：−1 +1，净牌差 0。
- 队友间转移：不改变团队总牌数，不再次记摸牌收益。
- 额外伤害、有效回血、防伤均按每点 2 牌；主动失去体力按同样价值扣除。
- 被动卖血的基础受伤已经在共同场景里，不能再扣一次；若伤害被防止，该次受伤收益也不能同时触发。
- 限定/游戏开始/首次效果只计一次；明确互斥选项只取理想场景下最好的一项，不全部相加。
- 判定仍需使用概率。例如标准铁骑红色按 1/2、洛神连续黑判定用有限期望，不能把“理想”解释成无限好运。

**小额加分**：每次强中额外 0.15 CE（0.75 分），最多两次；装备破坏额外 0.1 CE（0.5 分），场景初始敌人只有一件装备且不预设补装，不能两轮重复拆同一件。装备牌本身的牌差已经单独结算。

因此甘宁奇袭每轮黑牌换一次拆牌，净牌差为 0，两轮只额外计初始一件装备的 0.5 分。马超标准铁骑只按判定概率获得少量强中分，不在已经假定命中的基础输出上再加一份伤害。张辽单挑只偷一个敌人，替代正常摸两张，牌差为 0；地主或 2v2 能偷两个敌人时，才有每轮额外 2 牌差。

## 三模式

两轮出伤/受伤次数在所有模式相同，不继续使用旧版 0.6 受伤频率、3/4 回合窗口或地主 1.4 倍受伤系数。模式差异来自真实目标数、队友是否存在、技能合法性和身份：

```text
斗地主分 = (地主分 + 农民分) / 2
全局定价分 = (KOF 分 + 斗地主分 + 2v2 分) / 3
```

模式禁用仍显示不可用并按原定价约定计 0；不会把不能进入原生模式的武将排成可选项。卡牌详情可展开四个身份场景的分数、两轮牌差、血差和额外加分。

## 精度边界

这是理论收益估算器，不是完整对局求解器。基础技能有独立校准；未知 X/Y、觉醒/使命、额外回合、多刀、复杂分支、配合链等保留“待复核”和较低模型可信程度，不伪装成实测胜率。

固定一次基础输出也会低估依赖多次用杀的武将；模型不凭空假定无限杀、额外濒死救援或所有觉醒都能在两轮内完成。后续需要新增具体技能校准，而非按技能数量发分。NPC 营业速算胜负继续服务经营，不作为理论评分正确性的验证数据。

## 固定发行

`data/print-editions.json` 登记 16 个在售主题、1381 个主题印刷条目。它与当前强度评分分开：

- 本次发行冻结此前的主题印刷等级与两套配方，不通过新分数自动改成另一种配方。
- 标准配方：120 张 = 60N / 42R / 15SR / 3SSR。
- 已登记的无 SSR 发行配方：120 张 = 60N / 42R / 18SR / 0SSR。后续解锁 SSR 主题不会把它临时升级。
- 每盒 24 包、每包 5 张；每包固定四个基础槽和一个 R+ 槽；散包按固定槽位概率，卡盒按固定数量分配。
- 只从本主题已登记的印刷池出货，取消因解锁或评分缺档而跨主题补位。
- `printVersion` 由发行版本决定，不再每天随报价或评分版本变化。印刷配比和印刷等级不会因改分、改价格或解锁主题改变。
- 旧包盒内已经封装的内容不重抽，旧卡的印刷等级不改变。
- 当前“全局强度分级”仍可随模型变化，表示战力分档；它不代表实物被重新印成了另一稀有度。市场准入依然按实物印刷等级。

未来要调整出货、增加武将或镀层，明确新增发行版本并登记池；不要在游戏运行时按评分自动修补配方。

## 修改接口

| 文件 | 用途 |
| --- | --- |
| `data/strength-modes.json` | 两轮环境、1血2牌、分数换算、小额奖励与模式人数 |
| `data/ideal-yield-anchors.json` | 按技能 ID 登记的确定性每轮收益和说明 |
| `modules/backend/ideal-yield.mjs` | 触发次数、明确血牌变化、成本与合法目标的估算 |
| `modules/backend/strength-modes.mjs` | 分身份评分与三模式平均 |
| `modules/backend/strength-modes-legacy.mjs` | 读取旧模型、迁移前保留旧估算接口 |
| `data/print-editions.json` | 独立发行版本、固定印刷等级与盒配额 |
| `modules/economy-v7/collation-policy.mjs` | 固定配方校验、槽位概率与本主题印刷池 |
| `frontend/combat/pack-selector.mjs` | 卡包浏览、模式排序、跨包已选条；不改库存或结算 |
| `tools/build-mode-strength-report.mjs` | 重建评分审计报告；不改原生引擎或玩家存档 |

选将 DTO 新增 `themeId/themeName/roleScores`，保留原有字段。发行卡册新增 `issuanceRarity`，和 `currentRarity`（强度分档）分开。确认整场备战仍只向后端提交已有实物引用，不允许前端以卡包或分数制造武将。

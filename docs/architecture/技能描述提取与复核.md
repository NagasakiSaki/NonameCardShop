# 技能描述提取与复核

本轮修复展示内容，`data/cards.json`、技能代码和评分输入保持原数据。完整展示从 `data/skill-texts.mjs` 读取，防止把关联技能全文重新计入收益论，意外改变价格或发行。

## 根因和现行路径

旧提取适配器让未知函数返回空字符串。上游以 `get.poptip(...)` 拼技能说明时，术语被吞掉：势贺齐“闪袭”变成“将一张当【决斗】使用”，“绮胄”丢掉多处“应机牌”。

新的提取专用捕获器保留 poptip/getInfo/translation 中间标识，收齐包内/跨包翻译、内联术语、规则、卡牌和战法名称后再解析。缺失引用不能静默变空；上游源只读，不运行技能效果，不改真实引擎或旧提取 adapter 的默认行为。HTML 转为可读纯文本，保留换行、实体和数值颜色提示；前端仍使用 textContent，不直接注入上游 HTML。

共编译 5,149 个包内技能记录，559 项展示变化（含术语恢复、解释、格式清理、动态提示），382 项有术语/关联解释，157 项有动态翻译。另有 10 项源中没有基础文案，明确提示查看源码和实时对局，不编造补充。

`modules/backend/skill-descriptions.mjs` 仅在详情查询补展示；原描述必须精确匹配编译基准，否则保留自定义或更新正文。版本、动态标记、其他状态说明均为可选 DTO 字段。基础页提示动态说明，以对局引擎实时技能提示为准；其他版本/FAQ 可折叠查看。选将同样经 catalog.detail 读取说明。

## 重建流程

```powershell
npm run skills:audit
npm run skills:audit -- --out .local/skill-review-new
npm run skills:build -- --out .local/skill-install-new
node tests/skill-texts.mjs
node tests/skill-texts-browser.mjs
```

默认只在新隔离目录生成候选和差异报告；不覆盖现有目录。`skills:build` 明确安装，仅写展示语料文件，不重建卡图、评分、包盒或订单。有未解析引用时拒绝安装，报告记录 41 项输入哈希、缺文案、动态/计算 getter、差异和生成器哈希。提取器锁定1.11.6，新内核需先审查格式。技能源、目录登记或提取器变化后要重建语料，测试会检测编译输入漂移。

不要为修文案直接运行旧 extract/bundle/balance:build：这些命令重建目录、代码、卡图或历史评分，范围更大。缺图和技能文字分别处理，本次不替换无源卡图。

## 复核与限制

- 全部 5,149 条关联登记技能，核验源哈希、非空结果、无残留占位符、覆盖规则、DTO 独立性及评分源不变。
- 浏览器原生 DOM 独立解析上游 4,559 段静态/模板正文，逐段按序检查可见文字；不复用生成器清理函数作为期望。此层检查发现并修复了上游缺分号 `&nbsp` 的显示问题。
- 真实 Host 详情检查术语、解释、源码和动态提示，覆盖桌面及390px。
- 计算 getter、继承和复杂动态状态与静态正文是不同证据。尚未自然逐局遍历所有技能状态；实战引擎的实时提示仍是当前状态依据。理论评分人工校准另行处理。

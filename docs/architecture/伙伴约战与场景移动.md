# 伙伴约战与场景移动

日期：2026-10-27。适用于源码开发版；由本轮用户要求新增伙伴下注活动。玩家真实引擎下注开关仍为关闭，不改变现有价格、发行、三赛制与高手日程。

## 玩家入口和规则

「高手伙伴 → 伙伴排班」可把已招募伙伴安排为 **约战赚钱（有输赢）**。与三种原经营岗位、休息互斥，仍占用一个当班名额；默认原岗位保留，旧档伙伴不会自动动用店款。

伙伴主动邀请店内空闲或已在等候牌友、持有三名不同可参赛武将且预算足够的顾客。顾客有概率拒绝；玩家正在排队或已有比赛时不抢桌。等候顾客接受后，将其队列锁转换为比赛锁，释放原桌费预留再托管，沿用其已经接受的桌费，不能重复收取或绕过其他锁。使用后台 KOF 模拟，营业继续，不启动真实引擎，不暂停、不追加玩家比赛的 30 分钟。

配置集中于 `data/partner-activities.json`：基础等额本金 60，稀有度差至少一级时用 0.5/1/2 倍；单场最高 150，同时不超过店款 3%、扣款后保留 1,000 周转金、顾客可用预算与当日剩余止损额度。少于半份基础本金不约战。每人每天最多三场，间隔 90 游戏分钟，净亏达到 180 停手；搜索间隔 10 游戏分钟。此为初始可调平衡参数，并非收入保证。

顾客使用其真实实物收藏。伙伴借用已经流通过的卡种，优先其挑战主题，再按评分补齐三名不同武将；不生成实物、不解锁新主题、不让未流通武将进入 NPC 牌局。默认武将评分基础上增加小幅专家经验项，最终模拟胜率保持 15%～85%，结果来自世界的存档 RNG。没有足够流通卡时等待。

## 资金与取消

- 登记时双方本金、顾客一份桌费一次扣入托管。伙伴不向店铺支付桌费，也不另收一份抽水。
- 胜者取双方本金，店铺收顾客的桌费。店方净赢/亏计入 `daily.matchNet`，桌费只计 `daily.service` 一次。
- 本金归还/技术退款直接归还可用余额；只有净盈利和桌费经过既有供应商欠款清偿，避免把退本金误算营业收入。剧情借款不自动扣。
- 路线失败或技术取消，全额退双方本金及顾客桌费，不生成正式胜负或战绩。取消不会消耗当天场次，但保留冷却，避免同帧重试循环。
- `partnerWager` 保存冻结金额、客户/伙伴身份与结算收据；校验其托管负债，完成后重复事件不再改款。读档保留冷却、次数及 RNG；日初回退自然一起回退。
- 实时流水显示约战托管、净胜负/桌费、技术退款；伙伴管理显示当日和累计战绩、净额与桌费。

后台登记复用 `registerNpcMatch`，只有可信伙伴调度传入 `partnerTeam`。伙伴专用资金函数位于 `partner-wager-accounting.mjs`；通用 `m.stake` 保持 0，不借此打开旧玩家下注接口。NPC 入座/离桌沿用正式两房路线。顾客打完离店，当班伙伴回主店岗位；改为休息的伙伴完成当前局后离店。

## 场景与待机

`frontend/world/pixel-camera.mjs` 对镜头的最终屏幕平移取整，保持世界坐标连续，禁止用 `camera.roundPixels=true` 把所有世界坐标提前取整。补上最终图像矩阵的取整，避免 Float32 运算在采样边界引入小数误差。跟随及角色插值使用按帧时长计算的指数系数。

整幅地板的 4 倍原始烘焙保留，但只在缩放变化时生成当前缩放的缓存图。行走时按 1:1 屏幕比例搬移缓存，避免浏览器在大图裁切后重复分数倍最近邻缩放引起纹理闪动。房间地图、碰撞、设施位置与无缝连接不变。

25 人使用独立 64×256 四向待机图；原八帧行走和用户立绘保留。来源与构建命令见[人物工具](../../tools/character-kit/README.md)。伙伴招募/到岗/返回岗位时朝下（正面），移动和入座仍保留对应动作。待机字段为可选，旧外观清单仍可回退原帧。

## 验证入口

- `node tests/partner-activities.mjs`：资金守恒、胜负平/退款、幂等、流通限制、风险上限、正式 advance 调度、流水和返回岗位。
- `node tests/world-motion-idle-browser.mjs`：实际 Phaser 镜头负向对照、七档缩放、同一地板区域逐像素一致、25 人四向独立待机、动画纹理切换和岗位 UI。
- `node tests/frontend-movement.mjs`：斜走/滑墙、双房无缝连续、点击设施和窄屏；`node tests/character-art.mjs`：600 帧脸部、行走与立绘的原浏览器/CLI 哈希。
- `npm run test:all`：当前正式全量；素材引用由 `tests/package-closure.mjs` 验证入包。没有以自动测试证明长期经济难度、真机主观手感或 EXE 已更新。

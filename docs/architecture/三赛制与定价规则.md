# 当前三赛制与定价规则

## 可玩赛制

| 赛制 ID | 界面名称 | 每方备战 | 单局上场 | 整场胜利 |
| --- | --- | ---: | --- | --- |
| `kof` | 1v1 三将接力 | 3 | 每方一将，按顺序接力 | 对方三将全部阵亡；不再额外打 BO3 |
| `doudizhu-bo3` | 斗地主换边 BO3 | 5 | 地主一将、农民两将 | 先两胜；有胜负的小局后交换地主方 |
| `versus2v2-bo3` | 2v2 BO3 | 8 | 每方两将，玩家主将＋AI 队友 | 先两胜；按队伍判胜负 |

独立 `bo3` 已从正式赛制注册表、界面选项和登记入口删除，不能通过旧命令重新创建。默认赛制为 `kof`。三将接力换将重新摸四张，不继承手牌或装备。斗地主和 2v2 的原生引擎 profile、同伴可选接管、能力检查保持现有边界。

正式房间入口提供三种玩法；旧式等候报名入口专用于三将接力，后台 NPC 自动报名也改为持有三名不同流通武将后参加接力，不再开单将 BO3。两种多人赛制可在正式房间等候具备足够阵容的对手。

## 高手挑战

高手不再限制单一赛制，玩家可以选择三种玩法之一。阶段邀请默认三将接力，不在切换玩法时清除已选高手。

1. 按所选玩法从对应解锁主题抽取 3/5/8 名不同兼容武将。
2. 当前挑战分别缓存每种赛制的公开备战池；取消或切换回来不会重抽。
3. 主题若没有足够兼容武将，明确告知并要求换玩法，不偷偷降级为其他模式。
4. 正式确认时记录实际赛制。解锁验证依据注册表要求：KOF 整场一胜；斗地主、2v2 整场两胜。不能用“一胜”的参数伪造多人 BO3 通关。
5. 仍仅接受受信任引擎桥确认的完整赛果。胜利后的供货解锁、招募伙伴、回执、费用和释放占用同事务提交。玩家整场比赛仅推进一次 30 分钟；NPC 后台比赛不暂停世界。

## 评分和价格

```text
斗地主分 = (地主身份分 + 农民身份分) / 2
武将全局分 = (KOF分 + 斗地主分 + 2v2分) / 3
主题均分 = 本主题全部武将全局分的算术平均
```

已删除 BO3 评分场景与额外权重。三项等权，模式禁用依旧记该项 0 分并在选将中禁用，不缩小分母。单卡行情的战绩修正也改用三项等权，不再混入旧 BO3 统计。

当前模型 `resource-three-mode-3`，评分版本 `global-three-mode-5`。资源向量、身份参数和稀有度界线沿用可解释规则估算，仍不代表实测胜率或官方排名。

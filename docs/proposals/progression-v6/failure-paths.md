# 业务异常、失败分支与抗阻塞规范 (failure-paths.md)

> **任务标识**：CV6-04 成长任务与内容配置
> **核心验收场景**：N01, N04, N07, N08, G01
> **核心原则**：不把承诺当作已完成；模拟赛果绝不发牌技资格；一次性奖励严禁重复发放；所有逆境分支均有合法出口。

---

## 1. 常见经营异常与抗阻塞规则 (N08 合规)

### 1.1 缺卡与断货处理
- **问题**：货架所有密封卡包售罄，或玩家在未进货情况下开门营业，无法达成 `sales >= 1`。
- **业务表现**：进店顾客在货架前触发 `FeedbackReason: 'out-of-stock'`，不购买并记入未转化日志。
- **剧情应对**：
  - 林澄在柜台提醒：“货架空了，客人转一圈就走。去收银台翻翻进货单，哪怕先订两包试水。”
  - 触发孟岚的订货指引，不扣罚玩家信用，主线任务 `quest_day01_first_receipt` 保持等待监听，次日补货上架后自然继续。
- **严禁行为**：严禁系统凭空在玩家背包中凭空注入免费卡包伪造已完成。

### 1.2 缺钱与资金链紧张处理
- **问题**：玩家在第3或第5章流动资金不足，无法支付赛事承办费或赞助战队（`cash < 1000`）。
- **业务表现**：主线晋级任务提示“【建议积累流动资金】”，但不阻止玩家继续开门接待日常散客。
- **剧情应对**：
  - 顾衡发来邮件：“赛程报名截止还有充裕时间，先把每天的单卡寄售和散包周转做好，资金健康再来谈赞助。”
  - 允许玩家通过自由营业（`free-play`）无限天数积累利润，直到达到安全门槛后主动与 NPC 确认推进。
- **严禁行为**：严禁强制宣布玩家破产删档，或强行发放无法偿还的高利贷。

### 1.3 办赛缺人与参赛选手不足处理
- **问题**：周五晚间交流会需要 4 名持牌选手，打烊时店内仅有 2 名选手到场。
- **业务表现**：活动调度器检测到 `actualPlayers < requiredPlayers`，无法开启正规赛程。
- **剧情应对**：
  - 林澄主动提议：“今晚人没到齐，不勉强办大轮次。两位来的朋友先打一场友谊练习，桌费减半，下周五我们重新召集。”
  - 报名费如数退还，记录 1 场普通对局，活动状态变更为 `deferred`，不扣除店铺声誉。
- **严禁行为**：严禁无名杀引擎私自克隆两个同名 NPC 强行凑数。

## 2. 牌技考核与资格认证规范 (N07 合规)

1. **模拟赛果不发资格**：
   - 在 `assessments.json` 中，所有资格（如 `qual_player_novice`, `qual_host_community`, `qual_chenchuan_competitor`）的判定必须通过真实的无名杀规则引擎回调（`verificationPolicy: "engine-natural-or-controlled"`）。
   - 后台的快速概率模拟（`simulated = true`）仅可用于普通散客之间的后台对局，**严禁使用模拟结果给店长或关键角色发放正式资格！**
2. **考核战败的处理**：
   - 周野切磋或资格测试战败时，系统返回清晰战报，考官 NPC 触发战术复盘对话；
   - 考官提示：“你的卡组在低费过牌上存在短板，建议调整两张随从再来。”
   - 允许无限制重试，冷却时间为 0，不扣除报名费或降低现有评级。

## 3. 一次性奖励幂等性与防刷机制 (N04 合规)

在 `contracts/shop-experience.d.ts` 与后端事务中，所有主线任务奖励必须绑定唯一的持久化回执键（`onceOffKey`）：

```text
world.narrative.consumedEffects: Set<string>
```

- **发放前核验**：在分发资金 `reward.cash` 或声誉 `reward.reputation` 之前，必须先在事务中执行：
  ```javascript
  if (world.narrative.consumedEffects.has(quest.reward.onceOffKey)) {
    // 已经领取过该奖励，静默忽略或仅显示已领取提示，绝不二次增加资金
    return { success: true, duplicate: true };
  }
  ```
- **原子提交**：资金增减、任务状态置为 `completed` 以及将 `onceOffKey` 写入 `consumedEffects` 必须在同一事务提交，杜绝网络重发或读档回滚刷钱漏洞。

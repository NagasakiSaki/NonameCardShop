# V7 手动试玩问题清单

> 2026-10-26 更新：已删除单将 BO3。请新建存档，按 [三赛制与定价规则](../architecture/三赛制与定价规则.md) 测试。下方历史四模式检查项不再适用。

本次优先测：开桌只有三将接力、斗地主换边 BO3、2v2 BO3；高手在三种模式间切换后仍保持为对手；KOF 全部击败三将后直接结算解锁；另外两种先两胜。卡牌详情仅显示三模式，定价为三项等权均分。

适用：2026-10-26 开发版，包含后续对战房间与四模式评分。使用开发版游戏页面；本轮功能没有打进旧 EXE。

建议新建一个独立的测试存档，原来的游玩存档保留。每项可记为：通过 / 有问题 / 未测。**先测标有“优先”的项目**，其余在正常经营过程中补测；不必一次完成，也不需要看代码或控制台。

重点记录两类情况：功能出错，以及“虽然能用，但我不想再这样操作第二次”。后者同样是有效反馈。

## 本次新增：房间与评分（优先）

- [ ] R01：创建房间后，在我方尚未确认时就能看到对方完整备战池；卡面和技能按钮正常。四种模式名单分别为 1/3/5/8 名。
- [ ] R02：查看双方名单、翻页、关闭后，我方已选不丢；手机窄屏无按钮被挡。对方名单不能被我方点击修改。
- [ ] R03：没有足够持卡的 NPC 时能关窗继续经营；返回同一房间，NPC 到店后能自动加入。等候不冻结游戏时间，打烊或过期后释放桌位。
- [ ] R04：确认我方名单、开始实战后，对方整场池与此前公开的一致。取消重开高手房间不会刷新高手名单。
- [ ] R05：未开赛房间取消后不卡桌、不锁 NPC、不额外收费；读档后旧窗口操作不会错误作用于新分支。
- [ ] R06：卡牌详情同时显示 BO3、KOF、斗地主、2v2 分和全局均分；斗地主还显示地主/农民分。全局均分确为四项等权平均，禁用模式有解释。
- [ ] R07：供货价格仍为 210/360/510 三档；璀璨星河、移动版现在属于 210 档。一将成名开局仍为进货150、零售210。
- [ ] R08：旧实体卡印刷稀有度、旧密封盒内容和旧进货成本不因评分更新改变。当前稀有度变化应能与印刷标签区分。

## 第一轮：新店能否顺利运转

- [ ] **A01【优先】启动与新档**：能找到新建存档、选择存档、日档管理；退出再进入能找到自己的店铺，不会误进其他存档。
- [ ] **A02【优先】开局物品**：新档仓库有且只有一份赠礼——一将成名卡盒；重新打开游戏、读档不会额外补发。
- [ ] **A03【优先】初始供货**：只有一将成名可以进货；其他主题显示锁定及原因。新一将成名、线下武将、标准包不再出现在正常供货目录；普通“一将成名”仍存在。
- [ ] **A04【优先】价格**：初始一将成名散包进货 150、建议零售 210；卡盒进货 3420、建议零售 4790。后续主题的价格对照下表；伙伴优惠、手工定价、旧商品保留价格属于正常例外。
- [ ] **A05【优先】第一笔采购**：购买 1 包，再试一次多项购物篮。货物立即进入仓库，扣款与采购回执数量一致，不需要额外等收货。
- [ ] **A06【优先】拆盒与拆包**：拆盒得到 24 包；只拆指定数量，不多拆或少拆。拆包不会再次扣进货款；结果能看到卡面、稀有度和重复数量。
- [ ] **A07【优先】第一笔零售**：上架卡包、开门、关闭所有交互窗口后，确实有顾客购买；流水、现金、在架数量同步变化。
- [ ] A08：散包与整盒可以分别上架、撤下、调整价格；只改目标商品，不误改其他商品。
- [ ] A09：一键开所有包能处理选定范围；“保留一张、其余上架”能说明保留方式，不误卖受保护或参赛中的副本。
- [ ] A10：任务完成后奖励自动到账一次。反复打开任务页、重进游戏，不会重复领奖，也不需要再点领取。

第一天可把赠送盒拆成散包，先自开约 6 包、上架其余卡包，兼顾选将与第一笔营业收入。这只是试玩建议，不是游戏限制。另开一份测试存档再做“整盒全部开完”的配比核对，避免把唯一赠礼全部消耗后误判经营起步困难。

## 第二轮：时间、顾客和操作手感

- [ ] **B01【优先】交互暂停**：分别打开进货、仓库、拆包、单卡市场、垃圾桶、任务和存档窗口，观察游戏时间是否暂停；关闭全部窗口后应恢复原来的运行状态。
- [ ] **B02【优先】叠加窗口**：从选将打开卡牌详情，再逐层关闭。剩余窗口还开着时应继续暂停；全部关闭后，不应无故永久暂停。原本手动暂停的情况不应被擅自恢复。
- [ ] **B03【优先】顾客离店**：正常购物、没买到东西、开完卡包和打完牌的顾客，最终都能结束访问；不会一直堵门、挤成一团或卡在家具旁。
- [ ] B04：移动可走斜线；键盘、鼠标寻路都顺手。手动移动能取消先前的自动前往目标，不会突然被拉回。
- [ ] B05：跨房间连贯，不出现黑屏、错位、被弹回出口或反复来回切换。
- [ ] B06：每个 NPC 的中文姓名、类别清楚，跟随正确角色；紫名高手容易辨认。多人聚集时标签不会严重遮挡人物和器具。
- [ ] B07：正面双眼、左右侧脸、背面和摆臂正常；衣服不遮掉整个行走动作。店长换皮肤后四向动画仍正确。
- [ ] B08：顾客付款后走到拆包位置；不想要的卡进入公共垃圾桶。没有付款、没有拆包时，不应凭空出现一批“开出的卡”。
- [ ] B09：店长能丢卡并捡回；其他拾牌 NPC 也能拿走桶里的卡。卡被别人捡走后不能再重复拾取。
- [ ] B10：开始第二天后，前一天垃圾桶清空；普通收藏和在架商品不会一起消失。
- [ ] B11：不同顾客的购买行为有区别。观察多次来访，是否有人买进阶包、旗舰包和整盒；记录滞销主题、标价和持续天数。不要因一次没成交就判断预算有问题。
- [ ] B12：把窗口缩窄或改变浏览器缩放，按钮、确认、翻页仍能找到；卡面与技能可查看。记录必须滚动才能找到关键按钮、文字看不懂、关闭按钮出界的页面。

## 第三轮：高手挑战是否形成成长流程

新档第 3 天起有第一阶段高手；后续阶段基准为第 6、9、12、15 天等。**前一个阶段未通关、延期或未完成时，后续高手会等待，不保证届时全部同时出现。** 旧档首次迁移从启用后的下一天开始，不按新档第 3 天计算。

- [ ] **C01【优先】首次来访**：第 3 天营业期间，高松灯以紫名 NPC 实际进入店内，走近店长后邀请；没有一开局就固定站在门口的假顾客，也不会重复出现两个同名高手。
- [ ] **C02【优先】对话表现**：邀请是世界场景底部对话框，有姓名、立绘和清晰选项；出现时自动暂停，按键不会穿透成走路、开器具或误选选项。
- [ ] **C03【优先】延期**：选择“改天再战”，或用 Esc/关闭按钮退出。高手离开，次日再次来访；延期不会扣钱、提前解锁或算作败北。
- [ ] **C04【优先】接受挑战**：接受后能够前往牌桌、选将并真正开始 BO3；不因高手没有普通商品库存而无法开局。
- [ ] **C05【优先】输赢与解锁**：只赢一小局不能解锁；输掉整场不解锁。赢下完整两胜系列赛后，目标主题可进货，伙伴加入；重复点结果或刷新不会再次发一遍奖励。
- [ ] C06：输掉挑战后，可以重新交谈重试，也可以延期；不会一直显示“正在对局”导致双方都不能行动。
- [ ] C07：高手使用即将解锁主题里的武将。挑战借用卡不会作为免费实物突然出现在店长收藏、货架或垃圾桶里。
- [ ] C08：同一天通关后不会马上连刷下一名高手；拖延多个阶段后，也不会一次挤进来多位高手催战。
- [ ] C09：伙伴页能安排或取消工作；最多三人值班。引客、收银、供货的效果与文字相符，取消后对应效果消失；新报价变化不会改写已经买下的商品成本。
- [ ] C10：评价挑战难度：能否看懂对方怎么赢？是否需要合理准备？是否经常只能靠抽到更强将或反复碰运气？记录双方武将、比分和大致真实用时。

## 第四轮：四种对战和时间结算

两侧都需要足够的不同武将；普通 NPC 必须真正持有流通卡。人数不足时明确提示属于正常情况，不应临时凭空送武将。可以先积累卡牌，再测试多人模式。

| 模式 | 每方整场备战 | 单局上场 | 重点 |
| --- | ---: | --- | --- |
| BO3 | 1 将 | 每方 1 将 | 先两胜 |
| KOF | 3 将 | 每方依次 1 将 | 按备战顺序接力，不继承手牌 |
| 斗地主 BO3 | 5 将 | 地主 1 将、农民 2 将 | 有胜负后双方换地主；农民有 AI 队友 |
| 2v2 BO3 | 8 将 | 每方 2 将 | 主将由你操作，队友默认 AI |

- [ ] **D01【优先】开局与操作**：能进真实牌局、正常出牌、响应、发动技能及结算，没有 `Failed to fetch`、白屏或永久停住。发生停滞时记下双方武将、当时技能/卡牌和谁正在行动。
- [ ] **D02【优先】选将**：卡面、技能详情、分页、收藏置顶可用；跨页选择保留，同一阵营不能用重复武将凑人数。确认一次即可完成全部我方席位选择。
- [ ] **D03【优先】BO3**：比分能正确推进到 2:0 或 2:1；整场结束后牌桌、NPC 和参赛卡解除占用，可再次开局。
- [ ] **D04【优先】KOF**：按确认的顺序换将。没有额外技能影响时，新将重新摸四张，不带走前将手牌和装备；不会死一将就直接结束整场。
- [ ] **D05【优先】斗地主**：确认双方各备战五将；地主一将对两名农民。每个有胜负的小局后换地主阵营，平局不换；农民队友会自己行动。
- [ ] **D06【优先】2v2**：双方各备战八将、每局各上两将。主将阵亡而队友存活时继续对局，不能立刻判整队失败。
- [ ] **D07【优先】队友接管**：点击接管出现待切换提示，在安全回合边界生效；能交还 AI。主将阵亡后可以接管存活队友，不能接管敌人或死去的队友。无需期待按钮一按就打断正在结算的技能。
- [ ] **D08【优先】玩家比赛时间**：记录第一小局开始前的店铺时刻；整场进行中暂停，最后结果窗口尚未关闭时应比开始多 30 游戏分钟。不是每赢一小局都加 30 分钟。
- [ ] **D09【优先】NPC 比赛时间**：在没有其他弹窗、没有手动暂停时旁观 NPC 对局，店铺时间继续走；NPC 最终自动结束并付桌费、离桌，不无限占桌。
- [ ] D10：调高、调低、设为零的开桌费都可生效；店主不向自己付费。普通约战整场只认一次费用，高手挑战和伙伴训练免费，不因下一小局重复收费。
- [ ] D11：旧报名等待入口仍能使用；关掉报名窗口后，等待期间可自由移动或选择自动走动。取消报名能释放参赛卡。
- [ ] D12：尚未开局时取消，牌桌和卡牌立即释放，不记胜负；已经开局的情况走认输或恢复流程，不应伪装成通关。
- [ ] D13：在引擎载入途中关闭窗口、开局后关闭窗口，分别再进入。不能残留白屏或永久暂停；应明确提示重开当前局或放弃，保留已结束小局的比分。
- [ ] D14：如自然遇到平局，检查不乱加胜负；连续三次平局后有取消出口。很难遇到时标“未测”，不必刻意制造。
- [ ] D15：特殊技能、长连锁、主将死亡后的观战过程中，AI 能继续完成行动；没有需要店主代替敌人选择才能继续的隐蔽弹窗。

## 第五轮：存档与长期经营

- [ ] **E01【优先】日初回退**：在某天完成采购、开包、销售后读该日日档，回到当天 08:00 开店前。现金、欠款、库存、垃圾桶和经营进度都回退，不是只把时钟拨回去。
- [ ] **E02【优先】挑战回退**：当天打赢高手后读当天日初档，解锁、伙伴和奖励都应一起回退；再次正常打赢能重新解锁，不会被旧回执永久挡住。
- [ ] **E03【优先】重新启动**：关闭游戏再启动，存档还在；新档与旧档互不覆盖。读旧档不会重新赠送开局盒。
- [ ] E04：旧档已有武将、密封商品内容、印刷稀有度、成本和手工价格保留；停产不能把旧物品直接删除。
- [ ] E05：连续经营至少 5 天，最好到 15 天。正常销售是否支撑补货和营业成本，还是必须不断增加供应商欠款？
- [ ] E06：赠礼售罄后仍能经营。区分“赠品带来的收入”和“正常进货后的收益”，不要只看第一天赚了多少钱。
- [ ] E07：三档包是否都有购买需求；是否永远只卖最便宜的包、整盒无人问津、某个主题明显压倒其他主题？记录商品、价格、在架时间和是否遇到相应顾客。
- [ ] E08：单卡市场是否破坏经营平衡：低价无限买卖、同一张牌重复成交、重复上架、卖掉参赛卡、负余额或异常暴利。
- [ ] E09：每个阶段是否有值得准备的目标；挑战之间是否长时间无事可做，或者事情太多只能不停关窗口？
- [ ] E10：现有场景对话可以推进、选项可理解、立绘对应人物；关掉后能继续经营，不会在每次开窗口时重复播放同一句。
- [ ] E11：连续游玩后是否越来越卡、窗口越来越慢、顾客越来越拥堵；重新启动后是否恢复。记录大约第几天开始明显变化。
- [ ] E12：记录最想删掉的三次操作、最找不到的三个入口，以及最愿意继续玩的一个环节。

## 怎么反馈最方便

每个问题一条即可，不必先判断原因。能继续玩的小问题先记下来；卡死、存档丢失、钱或卡异常增减，优先反馈，不必坚持测满 15 天。

```text
编号：例如 D07
影响：无法继续 / 结果错误 / 体验不顺
测试存档与游戏日：
模式及双方武将（对战问题填写）：
操作顺序：1.…… 2.…… 3.……
实际发生：
我原本期待：
重开窗口/重启后是否还会发生：
截图或短视频：有则附上，没有也可以
```

### 当前已知边界，避免当成意外故障

- 当前没有开放赌注对局。
- 原生牌局中途关闭后不能原样恢复手牌和完整随机状态；应提供重开当前无赌注小局或放弃，并保留已经结算的比分。
- 没有足够持卡的 NPC 时，多人约战不能直接开局；应给出明确原因。
- 部分原生模式禁用武将不可选，但应显示原因，不能把已知不可用武将带进引擎后才白屏。
- 新档的第一盒没有 SSR 是当前设计：整盒 `60N / 42R / 18SR / 0SSR`。有合法 SSR 池的新盒为 `60N / 42R / 15SR / 3SSR`；散包没有跨包累计大保底。
- 解锁新主题不会把此前已经制造的旧盒内容改掉；不要用“解锁后开旧盒没有新卡”判断出错。
- 新剧情台本、店外世界尚未扩充，本轮主要检查现有对话呈现和经营/挑战流程。

# 无名小店 · Noname Card Shop

以武将卡牌为核心的卡店经营游戏原型：玩家经营卡店、拆包收藏、买卖单卡、经营牌桌，并参加高手挑战。技术路线为 **Phaser 像素世界 + HTML/CSS 界面 + JavaScript 经营规则 + 无名杀原生对战引擎**。

**2026-10-26：当前开发版本公开。** 本仓库包含源码和开发素材；最新修改以源码开发版为准，旧 EXE 尚未同步。明亮二次元场景与全设施重绘已有任务书，仍在开发中，不能视为已实装。

## 当前功能

- 独立卡店档案、新建/继续、按天回到当天开店时，以及精确时刻备份。
- 进货即入库、密封包盒货架、独立拆包台、自动收银、收藏与二级市场。
- 卡盒固定稀有度定额、散包出率与保底展示，旧实物保持原印刷版本和封装结果。
- NPC 购物/店内拆包/弃卡/拾卡、市场流通、后台模拟对战与实时收支。
- 每日自动领奖、阶段高手约战、主题解锁和经营伙伴。
- 三种玩家对战：**1v1 三将接力、斗地主换边 BO3、2v2 BO3**。多人模式接入原生无名杀，支持可选队友接管。
- 对战房间、公开对手备战池、两阶段选将与阵容锁定；KOF 换将重新摸四张，不继承手牌。
- 滚动选将和交易、保持滚动位置、每页一组大包盒与完整武将卡册、经营卡面右键查看技能。

详细规则以 [三赛制与定价规则](docs/architecture/三赛制与定价规则.md)、[滚动选将修复](docs/reviews/2026-10-26-滚动选将与卡包图鉴修复.md) 和当前代码为准。旧记录中的单将 BO3、四模式、旧价格、强制分页等不是当前规则。

## 启动开发版

主要开发环境：Windows，Node.js **22.12 或更新版本**、Git、Git LFS。卡图、音频等使用 LFS，缺少真实资源时不能只下载指针文件运行。

```powershell
git lfs install
git clone https://github.com/NagasakiSaki/NonameCardShop.git
cd NonameCardShop
git lfs pull
npm ci
node dev/start-game.mjs
```

也可在依赖准备完成后双击 `一键启动游戏.cmd`。开发页面为 `http://127.0.0.1:5190/frontend/index.html`，原生引擎使用 5191 端口。首次从启动页创建独立测试卡店。

不要直接双击 HTML 或使用 file://；启动器会检查服务版本与原生模式能力。进行中的对局结束后再刷新页面。

完整桌面开发、Electron 和浏览器测试依赖可以使用 `npm run setup` 安装，详见 [开发指南](docs/DEVELOPMENT.md)。开发版不要求先打包 EXE。

## 目录与贡献

| 目录 | 用途 |
| --- | --- |
| `frontend/` | Phaser 世界、主外壳、统一窗口、对话与三赛制房间 |
| `frontend-next/` | 正式经营组件、卡面交易、设施窗口与适配 |
| `modules/backend/` | 库存、钱包、出货、NPC、时钟、存档与规则 |
| `integration/` | Host 与原生无名杀模式接入 |
| `vendor/` | 已登记的上游引擎与库，保留原始声明 |
| `contracts/`、`data/`、`content/` | 接口、规则、注册与内容 |
| `tools/`、`tests/`、`docs/` | 素材工具、测试、维护与设计文档 |

欢迎报告可复现的问题和提交 PR。请注明存档类型、操作步骤、模式、截图与日志，移除私密信息；优先在独立测试档验证。资金/库存/存档只通过后端事务改变，真实胜负只通过引擎桥确认。

[当前前端专项任务书](任务分发/前端专项-明亮二次元卡店-2026-10-26/README.md) 明确了明亮二次元风格、所有设施细化重绘、文件边界和交付要求。其他候选实现进入正式目录前需要接线与回归，不把演示截图当正式功能。
